---
title: Wettbewerber auflisten
api: GET /v1/projects/{projectId}/competitors
---

Gibt Wettbewerber nach KI-Sichtbarkeit gerankt zurück: Visibility, Mention Rate, Citation Rate, Mentions, Share of Voice, Position und Sentiment. So siehst du, wie sich Finseo gegen andere Brands in den Antworten von ChatGPT, Claude und Perplexity schlägt.

Pro Wettbewerber werden drei Präsenz-Raten zurückgegeben, alle als Anteil an `totalResults` (siehe [KPIs erklärt](/de/getting-started/kpis)):

- `visibilityRate` — **Visibility**: % der Antworten, in denen die Marke sichtbar ist, d. h. im Antworttext genannt ODER ihre Domain als Quelle zitiert (die „Visibility"-Spalte im Dashboard; `visibleResults` ist die Anzahl). `visibilityIsMentionOnly: true` kennzeichnet Zeilen, bei denen der Citation-Anteil nicht ermittelt werden konnte und der Wert der rein mention-basierten Rate entspricht.
- `mentionRate` — **Mention Rate**: % der Antworten, die die Marke im Text nennen (`totalMentions` ist die Anzahl).
- `citationRate` — **Citation Rate**: % der Antworten, die die Domain der Marke als Quelle zitieren (`totalCitations` ist die Anzahl); `null`, wenn die Citations für die Marke nicht ermittelt werden konnten.

Eine Antwort kann sowohl in `mentionRate` als auch in `citationRate` zählen, daher gilt `visibilityRate ≤ mentionRate + citationRate`.

Pro Wettbewerber werden zwei Positions-Metriken zurückgegeben:

- `avgMentionOrder` — der ordinale **Position**-KPI: durchschnittlicher Rang unter allen in einer Antwort genannten Marken (1 = zuerst genannt, niedriger ist besser). Das ist der `#2.3`-Wert auf der Wettbewerber-Seite im Dashboard.
- `averagePosition` — **Mention Depth**: wie tief im Antwort*text* die Nennung erscheint (0 % = ganz oben). Keine Ranking-Position; der Name bleibt aus Kompatibilitätsgründen erhalten.

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Analysezeitraum, z. B. `7d`, `30d`.
</ParamField>

<ParamField query="model" type="string">
  Filtert die Tracking-Ergebnisse auf ein Modell.
</ParamField>

<ParamField query="language" type="string">
  Filtert Prompts nach Sprache.
</ParamField>

<ParamField query="tags" type="string">
  JSON-Array oder kommaseparierte Prompt-Tags.
</ParamField>

<ParamField query="search" type="string">
  Filter nach Substring im Wettbewerber-Namen oder in der Domain.
</ParamField>

<ParamField query="sortBy" type="string" default="visibility">
  Einer der Werte `visibility` (genannt ODER zitiert), `mentions`, `position`, `sentiment`, `name`.
</ParamField>

<ParamField query="sortDir" type="string" default="desc">
  `asc` oder `desc`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Seitennummer.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Seitengröße (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors?timeframe=30d&sortBy=mentions&limit=20' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "sortBy": "visibility", "limit": 20},
)
competitors = r.json()["data"]["competitors"]
print([c["name"] for c in competitors if c["isUserBrand"]])
```
