---
title: Projektdaten exportieren
api: GET /v1/projects/{projectId}/export
---

Exportiert Prompts mit verschachtelten Tracking-Ergebnissen für den gewählten Zeitraum. Gedacht für Offline-Analysen, BI-Tools oder Backups deiner Finseo-KI-Sichtbarkeitsdaten aus ChatGPT, Claude, Perplexity und weiteren Modellen.

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Rollierendes Zeitfenster der enthaltenen Ergebnisse (max. 1000 Prompts; Ergebnisse durch den Datumsbereich begrenzt).
</ParamField>

<ParamField query="model" type="string">
  Wird über das gemeinsame Schema geparst; der Export-Handler kann alle Modelle in den Ergebnissen einschließen.
</ParamField>

<ParamField query="language" type="string">
  Wird über das gemeinsame Schema geparst.
</ParamField>

<ParamField query="tags" type="string">
  Wird über das gemeinsame Schema geparst.
</ParamField>

<ParamField query="page" type="integer">
  Wird über das gemeinsame Schema geparst.
</ParamField>

<ParamField query="limit" type="integer">
  Wird über das gemeinsame Schema geparst.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/export?timeframe=30d' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/export",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d"},
)
export_payload = r.json()["data"]
print(export_payload["timeframeDays"], len(export_payload["prompts"]))
```
