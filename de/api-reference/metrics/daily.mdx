---
title: Projekt-Metriken (Zusammenfassung)
api: GET /v1/projects/{projectId}/metrics
---

Gibt aggregierte KI-Sichtbarkeits-Metriken für den aktuellen Zeitraum im Vergleich zum vorherigen Zeitraum gleicher Länge zurück. Ideal für Dashboards und KPIs zur Finseo-Sichtbarkeit in ChatGPT, Claude, Perplexity und weiteren getrackten Modellen.

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Rollierendes Zeitfenster, z. B. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Beschränkt die Metriken auf ein einzelnes Modell.
</ParamField>

<ParamField query="language" type="string">
  Filter nach Prompt-Sprache.
</ParamField>

<ParamField query="tags" type="string">
  JSON-Array oder kommaseparierte Tags, um Prompts zu filtern.
</ParamField>

<ParamField query="page" type="integer">
  Nur wegen des gemeinsamen Query-Parsings enthalten; Metriken ignorieren Pagination.
</ParamField>

<ParamField query="limit" type="integer">
  Nur wegen des gemeinsamen Query-Parsings enthalten; Metriken ignorieren Pagination.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics?timeframe=30d' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "language": "en"},
)
metrics = r.json()["data"]
print(metrics["current"]["visibilityRate"], metrics["changes"]["visibilityRateChange"])
```
