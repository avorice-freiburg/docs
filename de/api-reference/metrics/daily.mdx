---
title: Projekt-Metriken (Zusammenfassung)
api: GET /v1/projects/{projectId}/metrics
---

Gibt aggregierte KI-Sichtbarkeits-Metriken für den aktuellen Zeitraum im Vergleich zum vorherigen Zeitraum gleicher Länge zurück. Ideal für Dashboards und KPIs zur Finseo-Sichtbarkeit in ChatGPT, Claude, Perplexity und weiteren getrackten Modellen.

Die Antwort führt den aktuellen Zeitraum unter `today` und den Vorzeitraum unter `yesterday` (historische Namen — jeder Block aggregiert den gesamten Zeitraum, `date` ist das Enddatum des Zeitraums). Alle Raten teilen denselben Nenner, `totalResponses` (siehe [KPIs erklärt](/de/getting-started/kpis)):

| Feld | Bedeutung |
| --- | --- |
| `responseVisibilityRate` | **Visibility** — % der Antworten, in denen die Marke sichtbar ist: im Text genannt ODER eigene Domain als Quelle zitiert (der „Visibility"-KPI im Dashboard) |
| `mentionRate` | **Mention Rate** — % der Antworten, die die Marke im Antworttext nennen |
| `citationRate` | **Citation Rate** — % der Antworten, die die eigene Domain (oder einen konfigurierten Domain-Alias) als Quelle zitieren |
| `mentions` / `cited` | Absolute Zahlen hinter Mention Rate und Citation Rate (Antworten, jede einmal gezählt) |
| `visibilityRate` | Prompt-Abdeckung — % der getrackten Prompts mit mindestens einer sichtbaren Antwort (eine andere, meist höhere Zahl) |
| `visible` / `notVisible` | Anzahl der Prompts mit / ohne sichtbare Antwort |
| `position` | Mention Depth — wie tief im Antworttext die Nennung erscheint (0 = ganz oben), kein Ranking |

Eine Antwort kann sowohl in `mentionRate` als auch in `citationRate` zählen, daher gilt `responseVisibilityRate ≤ mentionRate + citationRate`.

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Rollierendes Zeitfenster, z. B. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Beschränkt die Metriken auf ein einzelnes Modell.
</ParamField>

<ParamField query="language" type="string">
  Filter nach Prompt-Sprache.
</ParamField>

<ParamField query="tags" type="string">
  JSON-Array oder kommaseparierte Tags, um Prompts zu filtern.
</ParamField>

<ParamField query="page" type="integer">
  Nur wegen des gemeinsamen Query-Parsings enthalten; Metriken ignorieren Pagination.
</ParamField>

<ParamField query="limit" type="integer">
  Nur wegen des gemeinsamen Query-Parsings enthalten; Metriken ignorieren Pagination.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics?timeframe=30d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "language": "en"},
)
metrics = r.json()["data"]
cur, chg = metrics["today"], metrics["changes"]
print(cur["responseVisibilityRate"], cur["mentionRate"], cur["citationRate"], chg["responseVisibilityRateChange"])
```
