---
title: Metriken-Zeitreihe
api: GET /v1/projects/{projectId}/metrics/timeseries
---

Gibt tägliche KI-Sichtbarkeits-Metriken für Charts zurück. Jede Zeile in `data.chartData` entspricht einem Kalendertag innerhalb des über `timeframe` abgeleiteten Zeitraums — oder innerhalb von `startDate` / `endDate`, wenn beide angegeben sind. Ideal für Trendlinien zu Finseo in ChatGPT, Claude und Perplexity.

Felder pro Tag (alle Zahlen sind KI-Antworten dieses Tages; siehe [KPIs erklärt](/de/getting-started/kpis)):

| Feld | Bedeutung |
| --- | --- |
| `totalResults` | Analysierte KI-Antworten an diesem Tag |
| `visible` / `notVisible` | Antworten, in denen die Marke sichtbar ist (im Text genannt ODER eigene Domain zitiert) / nicht sichtbar — `visible ÷ totalResults` ist die Dashboard-**Visibility** |
| `mentions` | Antworten, die die Marke im Text nennen — `mentions ÷ totalResults` ist die **Mention Rate** |
| `cited` | Antworten, die die eigene Domain (oder einen Domain-Alias) als Quelle zitieren — `cited ÷ totalResults` ist die **Citation Rate**. `null`, wenn der Tag aus einem Rollup ohne Citations stammt |
| `mentionOrder` | Durchschnittliche ordinale Position unter den genannten Marken (1 = zuerst genannt; der **Position**-KPI im Dashboard), `null`, wenn die Marke nicht genannt wurde |
| `position` | Mention Depth — wie tief im Antworttext die Nennung erscheint (0 = ganz oben) |
| `sentiment` | Durchschnittlicher Sentiment-Score (0–100) über die sichtbaren Antworten |
| `uniquePrompts` | Verschiedene Prompts mit mindestens einer Antwort an diesem Tag |

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Rollierendes Zeitfenster, wenn `startDate` / `endDate` nicht verwendet werden.
</ParamField>

<ParamField query="startDate" type="string">
  ISO-Datum `YYYY-MM-DD` (zusammen mit `endDate` verwenden).
</ParamField>

<ParamField query="endDate" type="string">
  ISO-Datum `YYYY-MM-DD` (zusammen mit `startDate` verwenden).
</ParamField>

<ParamField query="model" type="string">
  Filter auf ein Modell.
</ParamField>

<ParamField query="language" type="string">
  Filter nach Prompt-Sprache.
</ParamField>

<ParamField query="tags" type="string">
  JSON-Array oder kommaseparierte Tags.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries?timeframe=14d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "14d", "model": "chatgpt"},
)
series = r.json()["data"]["chartData"]
last = series[-1]
print(last["date"], last["visible"] / last["totalResults"], last["mentions"], last["cited"])
```
