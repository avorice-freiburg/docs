---
title: Projekt erstellen
api: POST /v1/projects
---

Erstellt ein neues Projekt. Finseo trackt die KI-Sichtbarkeit der Brand, die zu diesem Projekt gehört, in ChatGPT, Claude, Perplexity und den konfigurierten Modellen.


<ParamField body="name" type="string" required>
  Anzeigename (1–200 Zeichen).
</ParamField>

<ParamField body="language" type="string" required>
  Sprache für die Brand-Analyse und die generierten Prompts (Groß-/Kleinschreibung wird ignoriert).
  Zulässig sind: `en`, `de`, `fr`, `es`, `it`, `nl`, `pt`, `pl`, `sv`, `da`, `tr`, `ja`,
  `no`, `fi`, `cs`, `ru`, `zh`, `zh-tw`, `ko`, `hi`, `ar`, `he`.
</ParamField>

<ParamField body="websiteUrl" type="string">
  Kanonische Website-URL; wird verwendet, um `domain` abzuleiten, wenn diese fehlt.
</ParamField>

<ParamField body="domain" type="string">
  Root-Domain (z. B. `finseo.ai`). Optional, wenn `websiteUrl` angegeben ist.
</ParamField>

<ParamField body="description" type="string">
  Optionale Notizen (max. 500 Zeichen).
</ParamField>

<ParamField body="isPitch" type="boolean">
  Erstellt ein **Pitch-Projekt** ohne Projektgebühr, begrenzt auf 50 Prompts und
  mit automatischer Pausierung nach Ablauf des Pitch-Zeitraums. Ideal für
  einmalige Interessentenanalysen durch Sales Agents. Pitch-Slots sind je
  Agenturpaket begrenzt (z. B. 250 bei Agency Starter, 500 bei Agency Studio).
</ParamField>

<ParamField body="pitchDurationDays" type="number" default="14">
  Pitch-Zeitraum in Tagen: `1` (einmaliger Lauf), `7` oder `14`. Wird ohne
  `isPitch: true` ignoriert. Einen gewonnenen Pitch wandelst du mit
  [Projekt aktualisieren](/api-reference/projects/update) und `convertFromPitch`
  in ein Kundenprojekt um.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks"
  }'
```

```python Python
import requests

payload = {
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks",
}
r = requests.post(
    "https://api.finseo.ai/v1/projects",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
created = r.json()["data"]
print(created["id"])
```
