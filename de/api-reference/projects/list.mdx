---
title: Projekte auflisten
api: GET /v1/projects
---

Gibt eine Liste der Projekte zurück, auf die dein API-Key Zugriff hat. Projekte repräsentieren getrackte Brands oder Domains in Finseo für KI-Sichtbarkeit in ChatGPT, Claude, Perplexity und weiteren Modellen.

Jedes Projekt enthält `isPitch`. Pitch-Projekte enthalten zusätzlich `pitchDurationDays` (1, 7 oder 14) und `pitchExpiredAt` (`null`, solange das Pitch-Fenster offen ist). So erkennt ein Agent zuverlässig, wie lange ein Pitch noch läuft.


<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.finseo.ai/v1/projects \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

response = requests.get(
    "https://api.finseo.ai/v1/projects",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
)
projects = response.json()["data"]
for p in projects:
    print(p["name"], p["id"])
```

</RequestExample>
