---
title: Projekt aktualisieren
api: PUT /v1/projects/{projectId}
---

Aktualisiert ein bestehendes Projekt. Sende nur die Felder, die du ändern willst.

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>


<ParamField body="name" type="string">
  Neuer Anzeigename (1–200 Zeichen).
</ParamField>

<ParamField body="websiteUrl" type="string">
  Aktualisierte kanonische URL.
</ParamField>

<ParamField body="domain" type="string">
  Aktualisierte Root-Domain.
</ParamField>

<ParamField body="convertFromPitch" type="boolean">
  Auf `true` setzen, um ein Pitch-Projekt in ein vollständiges Kundenprojekt umzuwandeln – zum Beispiel nach einem erfolgreichen Abschluss. Die Umwandlung prüft einen freien Kundenprojekt-Slot und das Antwortbudget des Tarifs und aktiviert anschließend pausierte Prompts. Schlägt fehl, wenn das Projekt kein Pitch-Projekt ist.
</ParamField>

<ParamField body="description" type="string">
  Aktualisierte Beschreibung (max. 500 Zeichen).
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{"name": "Finseo — Growth", "description": "Primary Finseo GTM project"}'
```

```python Python
import requests

project_id = "67a1c2d3e4f5061728394a5b"
r = requests.put(
    f"https://api.finseo.ai/v1/projects/{project_id}",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json={"name": "Finseo — Growth", "description": "Primary Finseo GTM project"},
)
print(r.json()["data"])
```

</RequestExample>
