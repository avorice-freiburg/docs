---
title: Prompt erstellen
api: POST /v1/projects/{projectId}/prompts
---

Fügt einem Projekt einen neuen Tracking-Prompt hinzu. Finseo führt diesen Prompt auf den KI-Modellen des Projekts aus und erfasst die Sichtbarkeit deiner Brand im Vergleich zu Wettbewerbern in ChatGPT, Claude, Perplexity und den weiteren aktivierten Modellen.

Der Prompt wird sofort zur Verarbeitung eingereiht (`enqueued: true` in der Antwort); erste Antworten liegen in der Regel nach wenigen Minuten vor. Der Prompt erbt Domain, Markenname, Synonyme, Domain-Aliase und Tracking-Frequenz des Projekts — das Projekt braucht daher eine `websiteUrl`, sonst wird die Anfrage mit `400` abgelehnt.

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>


<ParamField body="prompt" type="string" required>
  Prompt-Text (1–500 Zeichen).
</ParamField>

<ParamField body="models" type="array">
  Optional. Standard sind die aktivierten Modelle des Projekts (die
  **Modell-Einstellungen** im Dashboard, zurückgegeben als `models` von
  [Projekt abrufen](/de/api-reference/projects/get)). Wenn angegeben, muss die
  Liste eine **Teilmenge** davon sein — ein Prompt kann nicht auf einem Modell
  laufen, das im Projekt nicht aktiviert ist, sonst würden Dashboard-Filter und
  Prompt-Daten auseinanderlaufen. Aktiviere Modelle zuerst für das Projekt über
  [Projekt aktualisieren](/de/api-reference/projects/update). Ein Modell
  außerhalb des aktivierten Sets wird mit `400` und einer Meldung abgelehnt, die
  mit `model_not_enabled` beginnt.
</ParamField>

<ParamField body="language" type="string">
  Sprach-/Marktcode für den Prompt (z. B. `de`, `en`). Standard ist die `language` des Projekts. Der Wert wird auf die Schreibweise des Dashboards normalisiert (`de` → `DE`), damit der Länderfilter greift.
</ParamField>

<ParamField body="tags" type="array">
  Optionale String-Tags zum Filtern in den Analysen.
</ParamField>

<Note>
  Pitch-Projekte (`isPitch: true`) sind auf **50 Prompts** begrenzt. Bei einem abgelaufenen Pitch werden neue Prompts abgelehnt. Wandle ihn zuerst über [Projekt aktualisieren](/api-reference/projects/update) in ein Kundenprojekt um.
</Note>

## Fehler

Es gelten dieselben Limits wie beim Hinzufügen eines Prompts im Dashboard.
Verletzungen liefern `403` mit `error.code = "FORBIDDEN"` und
`error.details.reason`:

| `details.reason` | Bedeutung |
| --- | --- |
| `prompt_limit` | Prompt-Limit deines Tarifs erreicht (`promptsUsed`, `promptLimit`). |
| `prompt_budget_exceeded` | Brand-Tarif: Dieser Prompt auf diesen Modellen würde das Prompt-Budget überschreiten (`promptLimit`, `slotsUsed`, `projectedSlots`). |
| `agency_limit` | Agentur: Die prognostizierten monatlichen Antworten übersteigen das inkludierte Kontingent und es gibt ein höheres Paket (`package`, `nextPackage`, `includedResults`, `projectedMonthlyAnswers`). Das höchste Paket wird nie blockiert; der Überschuss wird als Overage abgerechnet. |
| `pitch_prompt_limit` | Das Pitch-Projekt hat bereits 50 Prompts (`current`, `limit`). |
| `pitch_expired` | Das Pitch-Fenster ist geschlossen; wandle das Projekt zuerst um. |

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts \
  --header "Authorization: Bearer $FINSEO_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "language": "en",
    "tags": ["comparison", "Finseo"]
  }'
```

```python Python
import requests

payload = {
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "language": "en",
    "tags": ["comparison", "Finseo"],
}
r = requests.post(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
print(r.json()["data"])
```
