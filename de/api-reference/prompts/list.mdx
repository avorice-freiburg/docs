---
title: Prompts auflisten
api: GET /v1/projects/{projectId}/prompts
---

Listet die getrackten Prompts eines Projekts auf — mit Sichtbarkeit, Mention-Zahlen, Citations und Sentiment für den gewählten Zeitraum. Finseo wertet diese Prompts gegen ChatGPT, Claude, Perplexity und weitere Modelle aus.

Pro Prompt beziehen sich alle Zahlen auf die KI-Antworten des gewählten Zeitraums (`resultCount`; siehe [KPIs erklärt](/de/getting-started/kpis)):

- `isVisible` — die Marke war in mindestens einer Antwort sichtbar: im Antworttext genannt ODER die eigene Domain als Quelle zitiert
- `totalMentions` / `mentionRate` — Antworten, die die Marke im Text nennen, und diese Anzahl in % von `resultCount` (**Mention Rate**)
- `ownDomainCitations` / `citationRate` — Antworten, die die eigene Domain (oder einen konfigurierten Domain-Alias) als Quelle zitieren, und diese Anzahl in % von `resultCount` (**Citation Rate**)

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Länge des rollierenden Zeitfensters, z. B. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Filtert die Ergebnisse auf ein einzelnes Modell (z. B. `chatgpt`).
</ParamField>

<ParamField query="language" type="string">
  Filter nach ISO-Sprachcode (z. B. `en`, `de`).
</ParamField>

<ParamField query="tags" type="string">
  JSON-Array als String oder kommaseparierte Tag-Namen, um Prompts zu filtern.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive Substring-Suche im Prompt-Text.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Seitennummer (beginnend bei 1).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Seitengröße (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts?timeframe=30d&limit=10&page=1' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

params = {"timeframe": "30d", "limit": 10, "page": 1, "search": "Finseo"}
r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params=params,
)
body = r.json()["data"]
first = body["prompts"][0]
print(body["totalCount"], first["prompt"], first["mentionRate"], first["citationRate"])
```
