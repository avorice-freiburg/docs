---
title: Quellen auflisten
api: GET /v1/projects/{projectId}/sources
---

Listet Domains und URLs auf, die in KI-Antworten zu deinen getrackten Prompts als Citations auftauchen — nützlich, um zu verstehen, welche Quellen die Sichtbarkeit für Finseo-bezogene Anfragen in ChatGPT, Claude und Perplexity treiben.

<ParamField path="projectId" type="string" required>
  Projekt-ID.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Rollierendes Zeitfenster für Citations.
</ParamField>

<ParamField query="model" type="string">
  Filter nach Antwort-Modell.
</ParamField>

<ParamField query="language" type="string">
  Filtert Prompts nach Sprache.
</ParamField>

<ParamField query="tags" type="string">
  JSON-Array oder kommaseparierte Prompt-Tags.
</ParamField>

<ParamField query="search" type="string">
  Substring-Suche in Domain oder Titel.
</ParamField>

<ParamField query="sortBy" type="string" default="citations">
  Einer der Werte `citations`, `domain`, `type`.
</ParamField>

<ParamField query="sortDir" type="string" default="desc">
  `asc` oder `desc`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Seitennummer.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Seitengröße (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/sources?timeframe=30d&sortBy=citations' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/sources",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "search": "finseo", "limit": 25},
)
print(r.json()["data"]["sources"][0]["domain"])
```
