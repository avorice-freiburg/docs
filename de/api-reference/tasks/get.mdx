---
title: Task abrufen
api: GET /v1/projects/{projectId}/tasks/{taskId}
description: Lies einen Optimierungs-Task komplett — Beschreibung, Schritt-für-Schritt-Plan, die auslösende Evidenz und der strukturierte Content-Plan bei Content-Tasks.
---

Liefert den vollständigen Task: die komplette Beschreibung, einen Schritt-für-Schritt-Maßnahmenplan, die Evidenz (Datenpunkte und betroffene Prompts oder Quellen), die den Task ausgelöst hat, und — bei Content-Tasks — einen strukturierten `contentPlan` mit Zielseite, Template und den Prompts, die der Content abdecken soll.

Die `taskId` bekommst du aus [Tasks auflisten](/de/api-reference/tasks/list) (Feld `id`).

<ParamField path="projectId" type="string" required>Die Projekt-ID</ParamField>
<ParamField path="taskId" type="string" required>Die Task-ID (UUID) aus Tasks auflisten</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/tasks/05ba7f64-9c1e-4f2a-8d3b-1a2b3c4d5e6f' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/tasks/{task_id}",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)
task = response.json()["data"]

print(task["title"])
for i, step in enumerate(task["steps"], 1):
    print(f"{i}. {step}")
```

```javascript Node.js
const res = await fetch(
  `https://api.finseo.ai/v1/projects/${projectId}/tasks/${taskId}`,
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const { data: task } = await res.json();
console.log(task.title, task.steps);
```
