# Shopify

<Note>
Die Shopify-Integration ist **bald verfügbar**. Diese Seite beschreibt die geplante Funktionalität.
</Note>

Verbinde deinen Shopify-Store, damit der Finseo-Agent Produkt-SEO-Titel, Beschreibungen, Structured Data (JSON-LD-Schemas), Seiteninhalte und URL-Redirects optimieren kann — per natürlichsprachlicher Befehle wie „Optimiere die SEO-Titel meiner Top-5-Produkte".

## So wird es funktionieren

1. Klicke auf der Shopify-Karte unter **Integrations** auf **Connect** und gib deine Store-URL ein (z. B. `mystore.myshopify.com`).
2. Du wirst zu Shopify weitergeleitet, um Finseo per OAuth zu autorisieren — keine API-Keys zum Kopieren.
3. Nach der Autorisierung erhält der Agent Zugriff auf die Shopify Admin API und kann Produkte, Seiten, Collections, Structured Data und Redirects lesen und bearbeiten.
4. Jede Änderung erfordert deine Bestätigung, bevor sie angewendet wird.
