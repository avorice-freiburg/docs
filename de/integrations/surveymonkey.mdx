# SurveyMonkey

Du fragst in einer SurveyMonkey-Umfrage schon „Wie bist du auf uns aufmerksam geworden?"? Behalte sie — Finseo importiert die Antworten via Zapier oder Make.

<Warning>
SurveyMonkeys native Webhooks enthalten nur eine **Response-ID**, nicht die Antworten selbst. Verbinde SurveyMonkey über Zapier oder Make — die holen die vollständige Antwort für dich. SurveyMonkeys Webhook direkt auf Finseo zu richten funktioniert nicht.
</Warning>

## Setup via Zapier / Make

1. Erstelle einen Zap (oder ein Make-Szenario) mit dem Trigger **SurveyMonkey — New Response with details** (nur diese Variante holt die Antworten automatisch).
2. Füge die Aktion **Webhooks — POST** (JSON) hinzu, mit der URL:

```text
https://app.finseo.ai/api/attribution/webhook/YOUR_PROJECT_ID?token=•••
```

3. Body:

```json
{
  "channel": "<answer to 'How did you hear about us?'>",
  "freetext": "<open-text answer>",
  "respondentEmail": "<respondent email>"
}
```

4. Schalte den Zap an.

Finseo normalisiert den Antworttext automatisch in Kanäle und führt Antworten über die E-Mail mit späteren Bestellungen zusammen (90-Tage-Fenster).

## Troubleshooting

<AccordionGroup>
  <Accordion title="Der Trigger liefert nur eine Response-ID">
    Du hast den einfachen „New Response"-Trigger gewählt. Wechsle auf **New Response with details** — nur diese Variante enthält die Antworttexte.
  </Accordion>
  <Accordion title="Antworten kommen an, landen aber im Kanal „other"">
    Mappe deine SurveyMonkey-Antwortoptionen im Zap auf Kanalnamen (z. B. über einen Formatter-Schritt), oder füge in Finseo unter Attribution → Workflows Übersetzungsregeln hinzu.
  </Accordion>
</AccordionGroup>
