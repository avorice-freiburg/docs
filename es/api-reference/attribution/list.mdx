---
title: Listar atribuciones
api: GET /v1/projects/{projectId}/attribution
---

Obtén las respuestas paginadas de la encuesta de atribución de un proyecto. Filtra por categoría de canal, fuente y rango de tiempo.

<ParamField path="projectId" type="string" required>
  El ID del proyecto.
</ParamField>

<ParamField query="days" type="integer" default="30">
  Número de días hacia atrás.
</ParamField>

<ParamField query="category" type="string">
  Filtra por categoría de canal: `ai_search`, `organic_search`, `paid`, `social`, `referral`, `content`, `direct`, `other`.
</ParamField>

<ParamField query="source" type="string">
  Filtra por fuente de datos: `widget`, `hubspot`, `typeform`, `jotform`, `salesforce`, `api`, `api_bulk`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número de página.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Resultados por página (máx. 500).
</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/PROJECT_ID/attribution?days=30&category=ai_search' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```
</RequestExample>
