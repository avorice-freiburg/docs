---
title: Listar competidores
api: GET /v1/projects/{projectId}/competitors
---

Devuelve el ranking de competidores por visibilidad en IA: visibilidad, Mention Rate, Citation Rate, Mentions, Share of Voice, posición y Sentiment. Úsalo para ver cómo se posiciona Finseo frente a otras marcas en las respuestas de ChatGPT, Claude y Perplexity.

Se devuelven tres tasas de presencia por competidor, todas como proporción de `totalResults` (consulta [KPIs explicados](/es/getting-started/kpis)):

- `visibilityRate` — **Visibility**: % de respuestas en las que la marca es visible, es decir, nombrada en el texto de la respuesta O su dominio citado como fuente (la columna "Visibility" del dashboard; `visibleResults` es el recuento). `visibilityIsMentionOnly: true` marca las filas en las que no se pudo resolver la parte de citaciones y el valor equivale a la tasa basada solo en menciones.
- `mentionRate` — **Mention Rate**: % de respuestas que nombran la marca en el texto (`totalMentions` es el recuento).
- `citationRate` — **Citation Rate**: % de respuestas que citan el dominio de la marca como fuente (`totalCitations` es el recuento); `null` cuando no se pudieron resolver las citaciones de la marca.

Una misma respuesta puede contar tanto en `mentionRate` como en `citationRate`, por lo que `visibilityRate ≤ mentionRate + citationRate`.

<ParamField path="projectId" type="string" required>
  Identificador del proyecto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Ventana de análisis, p. ej. `7d`, `30d`.
</ParamField>

<ParamField query="model" type="string">
  Filtra los resultados de Tracking a un solo modelo.
</ParamField>

<ParamField query="language" type="string">
  Filtra los Prompts por idioma.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON o Tags de Prompt separados por comas.
</ParamField>

<ParamField query="search" type="string">
  Filtra por subcadena del nombre o dominio del competidor.
</ParamField>

<ParamField query="sortBy" type="string" default="visibility">
  Uno de `visibility` (nombrada O citada), `mentions`, `position`, `sentiment`, `name`.
</ParamField>

<ParamField query="sortDir" type="string" default="desc">
  `asc` o `desc`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número de página.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Tamaño de página (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors?timeframe=30d&sortBy=mentions&limit=20' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "sortBy": "visibility", "limit": 20},
)
competitors = r.json()["data"]["competitors"]
print([c["name"] for c in competitors if c["isUserBrand"]])
```
