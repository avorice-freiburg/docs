---
title: Listar Fan-outs
api: GET /v1/projects/{projectId}/fanouts
description: Obtén los Fan-outs de consultas de IA (sub-consultas relacionadas que los modelos de IA generaron al responder tus Prompts con Tracking), agregados y ordenados por frecuencia.
---

Los Fan-outs de consultas son sub-consultas relacionadas que los modelos de IA (ChatGPT, Claude, Perplexity, etc.) generan internamente mientras responden tus Prompts con Tracking. Este Endpoint los agrega a partir de todos los resultados de Tracking dentro de un periodo y los devuelve ordenados por número de apariciones.

Son los mismos datos que se muestran en la página Query Fan-outs del Dashboard de Finseo.

<ParamField path="projectId" type="string" required>El ID del proyecto</ParamField>
<ParamField query="timeframe" type="string" default="90d">Ventana de tiempo — `7d`, `30d`, `90d`, `365d`, o `all` para obtener todos los Fan-outs históricos</ParamField>
<ParamField query="startDate" type="string">Fecha de inicio personalizada (YYYY-MM-DD), tiene prioridad sobre timeframe</ParamField>
<ParamField query="endDate" type="string">Fecha de fin personalizada (YYYY-MM-DD), tiene prioridad sobre timeframe</ParamField>
<ParamField query="tags" type="string">Tags separados por comas para filtrar los Prompts de origen</ParamField>
<ParamField query="page" type="integer" default="1">Número de página</ParamField>
<ParamField query="limit" type="integer" default="50">Resultados por página (máx. 500)</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/fanouts?timeframe=30d&limit=20' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/fanouts",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"timeframe": "30d", "limit": 20}
)
fanouts = response.json()["data"]["fanouts"]

for f in fanouts:
    print(f"{f['query']} — {f['count']} occurrences across {f['promptCount']} prompts")
```

```javascript Node.js
const res = await fetch(
  `https://api.finseo.ai/v1/projects/${projectId}/fanouts?timeframe=30d`,
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const { data } = await res.json();
data.fanouts.forEach(f => console.log(f.query, f.count));
```
