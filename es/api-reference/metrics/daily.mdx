---
title: Métricas del proyecto (resumen)
api: GET /v1/projects/{projectId}/metrics
---

Devuelve métricas agregadas de visibilidad en IA para el periodo actual comparado con el periodo anterior de igual duración. Úsalo para dashboards y KPIs de la visibilidad de Finseo en ChatGPT, Claude, Perplexity y el resto de modelos con Tracking.

La respuesta incluye el periodo actual en `today` y el periodo anterior en `yesterday` (nombres heredados — cada bloque agrega el periodo completo y `date` es la fecha de fin del periodo). Todas las tasas comparten el mismo denominador, `totalResponses` (consulta [KPIs explicados](/es/getting-started/kpis)):

| Campo | Significado |
| --- | --- |
| `responseVisibilityRate` | **Visibility** — % de respuestas en las que la marca es visible: nombrada en el texto O propio dominio citado como fuente (el KPI "Visibility" del dashboard) |
| `mentionRate` | **Mention Rate** — % de respuestas que nombran la marca en el texto de la respuesta |
| `citationRate` | **Citation Rate** — % de respuestas que citan el propio dominio (o un alias de dominio configurado) como fuente |
| `mentions` / `cited` | Recuentos absolutos detrás de Mention Rate y Citation Rate (respuestas, cada una contada una vez) |
| `visibilityRate` | Cobertura de Prompts — % de Prompts con Tracking con al menos una respuesta visible (un número distinto, normalmente mayor) |
| `visible` / `notVisible` | Número de Prompts con / sin una respuesta visible |
| `position` | Profundidad de mención — a qué profundidad del texto de la respuesta aparece la mención (0 = al principio), no es un ranking |

Una respuesta puede contar tanto en `mentionRate` como en `citationRate`, por lo que `responseVisibilityRate ≤ mentionRate + citationRate`.

<ParamField path="projectId" type="string" required>
  Identificador del proyecto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Ventana móvil, p. ej. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Restringe las métricas a un único modelo.
</ParamField>

<ParamField query="language" type="string">
  Filtra por idioma del Prompt.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON o Tags separados por comas para filtrar Prompts.
</ParamField>

<ParamField query="page" type="integer">
  Incluido por el parseo de query compartido; las métricas ignoran la paginación.
</ParamField>

<ParamField query="limit" type="integer">
  Incluido por el parseo de query compartido; las métricas ignoran la paginación.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics?timeframe=30d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "language": "en"},
)
metrics = r.json()["data"]
cur, chg = metrics["today"], metrics["changes"]
print(cur["responseVisibilityRate"], cur["mentionRate"], cur["citationRate"], chg["responseVisibilityRateChange"])
```
