---
title: Serie temporal de métricas
api: GET /v1/projects/{projectId}/metrics/timeseries
---

Devuelve métricas diarias de visibilidad en IA para tus gráficas. Cada fila de `data.chartData` corresponde a un día natural dentro del periodo derivado de `timeframe`, o dentro de `startDate` / `endDate` cuando envías ambos. Ideal para líneas de tendencia de Finseo en ChatGPT, Claude y Perplexity.

Campos por día (todos los recuentos son respuestas de IA de ese día; consulta [KPIs explicados](/es/getting-started/kpis)):

| Campo | Significado |
| --- | --- |
| `totalResults` | Respuestas de IA analizadas ese día |
| `visible` / `notVisible` | Respuestas en las que la marca es visible (nombrada en el texto O propio dominio citado) / no visible — `visible ÷ totalResults` es la **Visibility** del dashboard |
| `mentions` | Respuestas que nombran la marca en el texto — `mentions ÷ totalResults` es la **Mention Rate** |
| `cited` | Respuestas que citan el propio dominio (o un alias de dominio) como fuente — `cited ÷ totalResults` es la **Citation Rate**. `null` cuando el día se sirvió desde un rollup que no incluye citaciones |
| `mentionOrder` | Posición ordinal media entre las marcas nombradas (1 = nombrada primero; el KPI **Position** del dashboard), `null` cuando la marca no fue nombrada |
| `position` | Profundidad de mención — a qué profundidad del texto de la respuesta aparece la mención (0 = al principio) |
| `sentiment` | Puntuación media de sentimiento (0–100) en las respuestas visibles |
| `uniquePrompts` | Prompts distintos con al menos una respuesta ese día |

<ParamField path="projectId" type="string" required>
  Identificador del proyecto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Ventana móvil cuando no se usan `startDate` / `endDate`.
</ParamField>

<ParamField query="startDate" type="string">
  Fecha ISO `YYYY-MM-DD` (úsala junto con `endDate`).
</ParamField>

<ParamField query="endDate" type="string">
  Fecha ISO `YYYY-MM-DD` (úsala junto con `startDate`).
</ParamField>

<ParamField query="model" type="string">
  Filtra a un solo modelo.
</ParamField>

<ParamField query="language" type="string">
  Filtro por idioma del Prompt.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON o Tags separados por comas.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries?timeframe=14d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "14d", "model": "chatgpt"},
)
series = r.json()["data"]["chartData"]
last = series[-1]
print(last["date"], last["visible"] / last["totalResults"], last["mentions"], last["cited"])
```
