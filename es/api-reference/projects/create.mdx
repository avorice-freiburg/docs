---
title: Crear proyecto
api: POST /v1/projects
---

Crea un proyecto nuevo. Finseo hará el Tracking de la visibilidad en IA de la marca asociada a este proyecto en ChatGPT, Claude, Perplexity y los modelos que tengas configurados.


<ParamField body="name" type="string" required>
  Nombre para mostrar (1–200 caracteres).
</ParamField>

<ParamField body="language" type="string" required>
  Idioma del análisis de marca y de los prompts generados (sin distinguir mayúsculas).
  Valores admitidos: `en`, `de`, `fr`, `es`, `it`, `nl`, `pt`, `pl`, `sv`, `da`, `tr`, `ja`,
  `no`, `fi`, `cs`, `ru`, `zh`, `zh-tw`, `ko`, `hi`, `ar`, `he`.
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canónica del sitio; se usa para inferir `domain` cuando no lo envías.
</ParamField>

<ParamField body="domain" type="string">
  Dominio raíz (p. ej. `finseo.ai`). Opcional si envías `websiteUrl`.
</ParamField>

<ParamField body="description" type="string">
  Notas opcionales (máx. 500 caracteres).
</ParamField>

<ParamField body="isPitch" type="boolean">
  Crea un **proyecto pitch** sin coste de proyecto, limitado a 50 prompts y
  pausado automáticamente al cerrar la ventana del pitch. Es ideal para
  análisis puntuales de prospectos realizados por agentes de ventas. Los
  paquetes de agencia limitan los slots (250 en Agency Starter y 500 en Agency Studio).
</ParamField>

<ParamField body="pitchDurationDays" type="number" default="14">
  Ventana del pitch en días: `1` (ejecución única), `7` o `14`. Se ignora si
  `isPitch` no es `true`. Convierte un pitch ganado en proyecto de cliente con
  [Actualizar proyecto](/api-reference/projects/update) y `convertFromPitch`.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks"
  }'
```

```python Python
import requests

payload = {
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks",
}
r = requests.post(
    "https://api.finseo.ai/v1/projects",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
created = r.json()["data"]
print(created["id"])
```
