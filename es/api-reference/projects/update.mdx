---
title: Actualizar proyecto
api: PUT /v1/projects/{projectId}
---

Actualiza un proyecto existente. Envía solo los campos que quieras cambiar.

<ParamField path="projectId" type="string" required>
  Identificador del proyecto.
</ParamField>


<ParamField body="name" type="string">
  Nuevo nombre para mostrar (1–200 caracteres).
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canónica actualizada.
</ParamField>

<ParamField body="domain" type="string">
  Dominio raíz actualizado.
</ParamField>

<ParamField body="convertFromPitch" type="boolean">
  Establécelo en `true` para convertir un proyecto pitch en un proyecto de cliente completo, por ejemplo al ganar el prospecto. La conversión comprueba que haya un slot de cliente libre y que el presupuesto de respuestas del plan cubra los prompts; después reactiva los prompts pausados. Falla si no es un proyecto pitch.
</ParamField>

<ParamField body="description" type="string">
  Descripción actualizada (máx. 500 caracteres).
</ParamField>

<ParamField body="models" type="array">
  Modelos de IA en los que se ejecutan los prompts del proyecto — el
  equivalente en la API de los **Model Settings** del dashboard. Reemplaza el
  conjunto completo y vuelve a sincronizar todos los prompts del proyecto
  (`syncedPromptCount` en la respuesta); la siguiente ejecución programada usa
  el nuevo conjunto. Valores admitidos: `chatgpt`, `perplexity`,
  `ai_overview`, `google_ai_mode`, `copilot`, `claude`, `gemini`, `grok`,
  `mistral`, `deepseek`.

  Se aplican los mismos límites que en el dashboard: el máximo de modelos de tu
  plan (3 en los planes Brand salvo que se haya ampliado), el presupuesto de
  prompts en los planes Brand y la franja de respuestas de IA incluida en los
  paquetes Agency. En el paquete Agency superior la llamada tiene éxito y
  devuelve un `meteredNotice` cuando la proyección supera las respuestas
  incluidas — el exceso se factura como consumo adicional, exactamente igual
  que en la UI.
</ParamField>

## Errores

Las infracciones de límites devuelven `403` con `error.code = "FORBIDDEN"` y un
`error.details.reason` legible por máquina:

| `details.reason` | Significado |
| --- | --- |
| `model_limit` | Más modelos de los que permite tu plan (`details.limit`). |
| `model_not_available` | Motor no disponible en tu plan (`details.models`). |
| `prompt_budget_exceeded` | Plan Brand: el nuevo conjunto de modelos superaría el presupuesto de prompts (`promptLimit`, `slotsUsed`, `projectedSlots`). |
| `agency_limit` | Agency: las respuestas mensuales proyectadas superan la franja incluida y existe un paquete superior (`package`, `nextPackage`, `includedResults`, `projectedMonthlyAnswers`) — o, en el caso de `convertFromPitch`, no hay ningún slot de cliente libre (`details.limit = "projects"`). |

```bash Establecer modelos
curl --request PUT \

  --header "Authorization: Bearer $FINSEO_API_KEY" \
  --header 'Content-Type: application/json' \
```

```python Python
import requests

project_id = "67a1c2d3e4f5061728394a5b"
r = requests.put(
    f"https://api.finseo.ai/v1/projects/{project_id}",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json={"models": ["chatgpt", "perplexity", "ai_overview", "claude"]},
)
if r.status_code == 403:
    print("blocked:", r.json()["error"]["details"]["reason"])
else:
    print(r.json()["data"]["models"])
```
