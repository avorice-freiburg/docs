---
title: Actualizar proyecto
api: PUT /v1/projects/{projectId}
---

Actualiza un proyecto existente. Envía solo los campos que quieras cambiar.

<ParamField path="projectId" type="string" required>
  Identificador del proyecto.
</ParamField>


<ParamField body="name" type="string">
  Nuevo nombre para mostrar (1–200 caracteres).
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canónica actualizada.
</ParamField>

<ParamField body="domain" type="string">
  Dominio raíz actualizado.
</ParamField>

<ParamField body="convertFromPitch" type="boolean">
  Establécelo en `true` para convertir un proyecto pitch en un proyecto de cliente completo, por ejemplo al ganar el prospecto. La conversión comprueba que haya un slot de cliente libre y que el presupuesto de respuestas del plan cubra los prompts; después reactiva los prompts pausados. Falla si no es un proyecto pitch.
</ParamField>

<ParamField body="description" type="string">
  Descripción actualizada (máx. 500 caracteres).
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{"name": "Finseo — Growth", "description": "Primary Finseo GTM project"}'
```

```python Python
import requests

project_id = "67a1c2d3e4f5061728394a5b"
r = requests.put(
    f"https://api.finseo.ai/v1/projects/{project_id}",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json={"name": "Finseo — Growth", "description": "Primary Finseo GTM project"},
)
print(r.json()["data"])
```

</RequestExample>
