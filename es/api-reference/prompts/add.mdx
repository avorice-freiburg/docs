---
title: Crear Prompt
api: POST /v1/projects/{projectId}/prompts
---

Añade un nuevo Prompt de Tracking a un proyecto. Finseo ejecutará este Prompt en los modelos de IA del proyecto y registrará la visibilidad de tu marca frente a competidores en ChatGPT, Claude, Perplexity y los demás modelos habilitados.

El Prompt se pone en cola para su procesamiento de inmediato (`enqueued: true` en la respuesta); las primeras respuestas suelen llegar en pocos minutos. El Prompt hereda el dominio, el nombre de marca, los sinónimos, los alias de dominio y la frecuencia de Tracking del proyecto, por lo que el proyecto necesita una `websiteUrl`; de lo contrario, la solicitud se rechaza con `400`.

<ParamField path="projectId" type="string" required>
  Identificador del proyecto.
</ParamField>


<ParamField body="prompt" type="string" required>
  Texto del Prompt (1–500 caracteres).
</ParamField>

<ParamField body="models" type="array">
  Opcional. Por defecto usa los modelos habilitados del proyecto (los **Model
  Settings** del dashboard, devueltos como `models` por [Obtener proyecto](/api-reference/projects/get)).
  Si se indica, debe ser un **subconjunto** de ellos — un prompt no puede
  ejecutarse en un modelo que el proyecto no tenga habilitado; de lo contrario,
  los filtros del dashboard y los datos del prompt no coincidirían. Habilita
  primero los modelos del proyecto mediante
  [Actualizar proyecto](/api-reference/projects/update). Un modelo fuera del
  conjunto habilitado se rechaza con `400` y un mensaje que empieza por
  `model_not_enabled`.
</ParamField>

<ParamField body="language" type="string">
  Código de idioma/mercado del Prompt (p. ej. `de`, `en`). Por defecto usa el `language` del proyecto. El valor se normaliza a la notación del dashboard (`de` → `DE`) para que coincida con el filtro de país.
</ParamField>

<ParamField body="tags" type="array">
  Tags de texto opcionales para filtrar en las analíticas.
</ParamField>

<Note>
  Los proyectos pitch (`isPitch: true`) están limitados a **50 prompts**. No se pueden añadir prompts a un pitch caducado; conviértelo primero en proyecto de cliente mediante [Actualizar proyecto](/api-reference/projects/update).
</Note>

## Errores

Se aplican los mismos límites que al añadir un prompt en el dashboard. Las
infracciones devuelven `403` con `error.code = "FORBIDDEN"` y `error.details.reason`:

| `details.reason` | Significado |
| --- | --- |
| `prompt_limit` | Se ha alcanzado el máximo de prompts de tu plan (`promptsUsed`, `promptLimit`). |
| `prompt_budget_exceeded` | Plan Brand: este prompt en estos modelos superaría el presupuesto de prompts (`promptLimit`, `slotsUsed`, `projectedSlots`). |
| `agency_limit` | Agency: las respuestas mensuales proyectadas superan la franja incluida y existe un paquete superior (`package`, `nextPackage`, `includedResults`, `projectedMonthlyAnswers`). El paquete superior nunca se bloquea; el exceso se factura como consumo adicional. |
| `pitch_prompt_limit` | El proyecto pitch ya tiene 50 prompts (`current`, `limit`). |
| `pitch_expired` | La ventana del pitch se ha cerrado; convierte primero el proyecto. |

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts \
  --header "Authorization: Bearer $FINSEO_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "language": "en",
    "tags": ["comparison", "Finseo"]
  }'
```

```python Python
import requests

payload = {
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "language": "en",
    "tags": ["comparison", "Finseo"],
}
r = requests.post(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
print(r.json()["data"])
```
