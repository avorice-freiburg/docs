---
title: Crear Prompt
api: POST /v1/projects/{projectId}/prompts
---

Añade un nuevo Prompt de Tracking a un proyecto. Finseo ejecutará este Prompt en los modelos indicados y registrará la visibilidad de tu marca frente a competidores en ChatGPT, Claude y Perplexity.

<ParamField path="projectId" type="string" required>
  Identificador del proyecto.
</ParamField>


<ParamField body="prompt" type="string" required>
  Texto del Prompt (1–500 caracteres).
</ParamField>

<ParamField body="models" type="array">
  Identificadores de modelos; por defecto `["chatgpt", "perplexity", "ai_overview"]`.
</ParamField>

<ParamField body="language" type="string" default="en">
  El valor predeterminado es `en`. **No** hereda el idioma del proyecto; indícalo explícitamente en proyectos que no estén en inglés.
</ParamField>

<ParamField body="tags" type="array">
  Tags de texto opcionales para filtrar en las analíticas.
</ParamField>

<Note>
  Los proyectos pitch (`isPitch: true`) están limitados a **50 prompts**. No se pueden añadir prompts a un pitch caducado; conviértelo primero en proyecto de cliente mediante [Actualizar proyecto](/api-reference/projects/update).
</Note>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "models": ["chatgpt", "claude", "perplexity"],
    "language": "en",
    "tags": ["comparison", "Finseo"]
  }'
```

```python Python
import requests

payload = {
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "models": ["chatgpt", "claude", "perplexity"],
    "language": "en",
    "tags": ["comparison", "Finseo"],
}
r = requests.post(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
print(r.json()["data"])
```
