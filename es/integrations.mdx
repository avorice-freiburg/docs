## Integraciones de Attribution

Las integraciones de Attribution usan una de estas dos opciones:

- Una URL de webhook de proyecto para formularios y CRMs.
- La Customer API para herramientas de automatización como Zapier, Make o n8n.

Las URLs de webhook se ven así:

```text
https://app.finseo.ai/api/attribution/webhook/PROJECT_ID?source=SOURCE&token=WEBHOOK_TOKEN
```

El parámetro `source` ayuda a Finseo a elegir el parser correcto. El `token` protege el endpoint.

## Fuentes de atribución compatibles

| Fuente | Vía recomendada | Notas |
| --- | --- | --- |
| HubSpot | Webhook de workflow | Requiere una acción de workflow de HubSpot que envíe un webhook. Para acciones nativas de webhook puede requerirse Data Hub Pro/Enterprise. |
| Salesforce | Flow HTTP Callout | Usa JSON de Flow Builder. Los Outbound Messages nativos de Salesforce envían XML y no son compatibles. |
| Typeform | Webhook nativo | Añade una pregunta "¿Cómo nos encontraste?" y envía todas las respuestas a Finseo. |
| Jotform | Webhook nativo | Finseo maneja las payloads multipart/form-data y `rawRequest` de Jotform. |
| Gravity Forms | Webhooks Add-On | Envía JSON y mapea el campo de atribución si es necesario. |
| Formstack | Webhook nativo | Envía los envíos de formulario como JSON. |
| Attio | Webhook nativo | Envía payloads de creación/actualización de registros con campos personalizados. |
| Pipedrive | Webhook de automatización | Envía campos de deal y persona desde automatizaciones. |
| Close | Webhook nativo | Envía eventos de lead o contacto. |
| Calendly | Suscripción de webhook | Envía las respuestas de los invitados desde las preguntas de reserva. |
| Intercom | Webhook nativo | Envía eventos de contacto o conversación con atributos personalizados. |
| Zapier / Make / n8n | Solicitud HTTP | Usa la Finseo API o un webhook genérico y mapea los campos manualmente. |

## HubSpot

1. En Finseo, abre **Integrations** y selecciona **HubSpot**.
2. Copia la URL del webhook.
3. En HubSpot, ve a **Automations -> Workflows**.
4. Crea un workflow disparado por un envío de formulario o la creación de un contacto.
5. Añade una acción **Send webhook**.
6. Pega la URL del webhook de Finseo.
7. Envía un lead de prueba y comprueba **Attribution** en Finseo.

Finseo busca campos comunes como `email`, `firstname`, `lastname`, `how_did_you_find_us`, `deal_amount` y `amount`.

## Salesforce

Usa **Flow HTTP Callout**, no los Outbound Messages nativos.

```json
{
  "LeadSource": "ChatGPT",
  "Email": "buyer@example.com",
  "Name": "Alex Buyer",
  "Id": "00Qxx0000012345",
  "Amount": 8500,
  "CurrencyIsoCode": "USD"
}
```

Finseo mapea `LeadSource` al canal de atribución, `Email` al email del respondente, `Name` al nombre del respondente, `Amount` al valor del deal y `CurrencyIsoCode` a la moneda.

## Typeform y Jotform

Para las herramientas de formularios, añade una pregunta como:

```text
How did you find us?
```

Buenas opciones de respuesta:

- ChatGPT
- Perplexity
- Claude
- Google
- Redes sociales
- Amigo o colega
- Anuncios
- Otro

Después añade la URL del webhook de Finseo en la configuración de webhooks del formulario. Finseo recibe el envío completo y extrae la respuesta de atribución.

## Zapier, Make y n8n

Úsalos cuando tu herramienta de origen no tiene un webhook nativo o cuando quieres transformar campos antes de enviarlos a Finseo.

```json
{
  "channelId": "{{how_did_you_find_us}}",
  "respondentEmail": "{{email}}",
  "respondentName": "{{name}}",
  "respondentExternalId": "{{crm_id}}",
  "dealValue": "{{amount}}",
  "dealCurrency": "{{currency}}",
  "metadata": {
    "source_tool": "zapier",
    "form": "{{form_name}}"
  }
}
```

Puedes enviar esto a la URL de webhook del proyecto o a la [Create Attribution API](/api-reference/attribution/submit).

## Mapeo de campos

Si una herramienta envía campos con nombres inusuales, envía primero una payload de prueba. Finseo crea un workflow de Attribution a partir de la estructura entrante. Abre **Attribution -> Workflows** y mapea los campos a:

- Respuesta de atribución
- Email
- Nombre
- Valor del deal
- Moneda del deal
- ID de formulario

Usa reglas cuando un campo de origen necesite traducirse. Por ejemplo, mapea `utm_source contains chatgpt` a `AI Search`.

## Checklist de pruebas

- Envía un envío de prueba desde la herramienta de origen.
- Confirma que la respuesta aparece en **Attribution**.
- Confirma que la categoría del canal es correcta, especialmente para fuentes de IA.
- Añade `dealValue` y `dealCurrency` si quieres reporting de ingresos.
- Añade un `respondentExternalId` estable como el ID del pedido, el ID del lead o el ID del deal.
- Mantén los nombres de campo consistentes entre mercados y países.
