# Linear

Conecta Linear para convertir tareas de Finseo en issues de Linear — incluida la descripción completa en markdown con la evidencia y los pasos recomendados. Ideal para equipos orientados a ingeniería que gestionan correcciones técnicas de GEO como crawlability o trabajo con datos estructurados.

## Qué puedes hacer

- Exportar cualquier tarea de Finseo como issue de Linear con un clic.
- Exportar automáticamente las tareas nuevas mediante reglas de automatización (filtradas por categoría e impacto).
- Asignar los issues exportados a miembros de Linear directamente desde Finseo.

## Obtén tu clave de API

1. En Linear, abre **Settings → Security & access**.
2. Bajo **Personal API keys**, haz clic en **New API key**.
3. Dale un nombre a la clave y cópiala — empieza con `lin_api_`.

Consulta la [documentación de claves de API de Linear](https://developers.linear.app/docs/graphql/working-with-the-graphql-api#personal-api-keys) para más detalles.

## Conexión

1. En Finseo, abre **Integrations → Linear → Connect**.
2. Pega la clave y guarda.

## Exportar tareas

- En la página **Tasks**, abre una tarea y usa **Export → Linear**, luego elige el equipo de destino.
- Opcionalmente elige un responsable en Linear.

## Reglas de automatización

Bajo **Tasks → Automation**, crea reglas que conviertan las nuevas tareas de Finseo en issues de Linear automáticamente — por ejemplo, cada tarea de la categoría **Technical** con impacto alto va directa a tu equipo de ingeniería.
