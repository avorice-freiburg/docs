---
title: Lister les attributions
api: GET /v1/projects/{projectId}/attribution
---

Récupérez les réponses paginées de l'enquête d'attribution pour un projet. Filtrez par catégorie de canal, par source et par plage temporelle.

<ParamField path="projectId" type="string" required>
  L'ID du projet.
</ParamField>

<ParamField query="days" type="integer" default="30">
  Nombre de jours d'antériorité.
</ParamField>

<ParamField query="category" type="string">
  Filtre par catégorie de canal : `ai_search`, `organic_search`, `paid`, `social`, `referral`, `content`, `direct`, `other`.
</ParamField>

<ParamField query="source" type="string">
  Filtre par source de données : `widget`, `hubspot`, `typeform`, `jotform`, `salesforce`, `api`, `api_bulk`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Numéro de page.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Résultats par page (max 500).
</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/PROJECT_ID/attribution?days=30&category=ai_search' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```
</RequestExample>
