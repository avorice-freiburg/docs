---
title: Lister les concurrents
api: GET /v1/projects/{projectId}/competitors
---

Renvoie le classement des concurrents en matière de visibilité IA : Mentions, visibilité, position moyenne et Sentiment. Utilisez cet Endpoint pour voir comment Finseo se positionne face aux autres marques dans les réponses de ChatGPT, Claude et Perplexity.

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Fenêtre d'analyse, p. ex. `7d`, `30d`.
</ParamField>

<ParamField query="model" type="string">
  Filtre les résultats de Tracking sur un seul modèle.
</ParamField>

<ParamField query="language" type="string">
  Filtre les prompts par langue.
</ParamField>

<ParamField query="tags" type="string">
  Tableau JSON ou Tags de prompts séparés par des virgules.
</ParamField>

<ParamField query="search" type="string">
  Filtre par sous-chaîne du nom ou du domaine du concurrent.
</ParamField>

<ParamField query="sortBy" type="string" default="mentions">
  L'une des valeurs `visibility`, `mentions`, `position`, `sentiment`, `name`.
</ParamField>

<ParamField query="sortDir" type="string" default="desc">
  `asc` ou `desc`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Numéro de page.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Taille de page (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors?timeframe=30d&sortBy=mentions&limit=20' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "sortBy": "visibility", "limit": 20},
)
competitors = r.json()["data"]["competitors"]
print([c["name"] for c in competitors if c["isUserBrand"]])
```
