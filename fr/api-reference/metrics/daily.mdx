---
title: Métriques du projet (résumé)
api: GET /v1/projects/{projectId}/metrics
---

Renvoie les métriques agrégées de visibilité IA pour la période en cours par rapport à la période précédente de durée égale. Utilisez cet Endpoint pour vos Dashboards et KPI de visibilité Finseo sur ChatGPT, Claude, Perplexity et les autres modèles suivis.

La réponse contient la période en cours sous `today` et la période précédente sous `yesterday` (noms hérités — chaque bloc agrège la période entière, `date` est la date de fin de la période). Tous les taux partagent le même dénominateur, `totalResponses` (voir [KPIs expliqués](/fr/getting-started/kpis)) :

| Champ | Signification |
| --- | --- |
| `responseVisibilityRate` | **Visibility** — % de réponses dans lesquelles la marque est visible : nommée dans le texte OU domaine propre cité comme source (le KPI « Visibility » du dashboard) |
| `mentionRate` | **Mention Rate** — % de réponses nommant la marque dans le texte de la réponse |
| `citationRate` | **Citation Rate** — % de réponses citant le domaine propre (ou un alias de domaine configuré) comme source |
| `mentions` / `cited` | Décomptes absolus derrière Mention Rate et Citation Rate (réponses, chacune comptée une fois) |
| `visibilityRate` | Couverture des prompts — % de prompts suivis avec au moins une réponse visible (un chiffre différent, généralement plus élevé) |
| `visible` / `notVisible` | Nombre de prompts avec / sans réponse visible |
| `position` | Profondeur de mention — à quelle profondeur du texte de la réponse la mention apparaît (0 = tout en haut), pas un classement |

Une réponse peut compter à la fois dans `mentionRate` et `citationRate`, donc `responseVisibilityRate ≤ mentionRate + citationRate`.

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Fenêtre glissante, p. ex. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Restreint les métriques à un seul modèle.
</ParamField>

<ParamField query="language" type="string">
  Filtre par langue des prompts.
</ParamField>

<ParamField query="tags" type="string">
  Tableau JSON ou Tags séparés par des virgules pour filtrer les prompts.
</ParamField>

<ParamField query="page" type="integer">
  Inclus pour l'analyse de requête partagée ; les métriques ignorent la pagination.
</ParamField>

<ParamField query="limit" type="integer">
  Inclus pour l'analyse de requête partagée ; les métriques ignorent la pagination.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics?timeframe=30d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "language": "en"},
)
metrics = r.json()["data"]
cur, chg = metrics["today"], metrics["changes"]
print(cur["responseVisibilityRate"], cur["mentionRate"], cur["citationRate"], chg["responseVisibilityRateChange"])
```
