---
title: Série temporelle des métriques
api: GET /v1/projects/{projectId}/metrics/timeseries
---

Renvoie les métriques quotidiennes de visibilité IA pour la création de graphiques. Chaque ligne de `data.chartData` correspond à un jour calendaire au sein de la période dérivée de `timeframe`, ou comprise entre `startDate` et `endDate` lorsque les deux sont fournis. Idéal pour tracer les courbes de tendance de Finseo sur ChatGPT, Claude et Perplexity.

Champs par jour (tous les décomptes sont des réponses IA de ce jour ; voir [KPIs expliqués](/fr/getting-started/kpis)) :

| Champ | Signification |
| --- | --- |
| `totalResults` | Réponses IA analysées ce jour-là |
| `visible` / `notVisible` | Réponses dans lesquelles la marque est visible (nommée dans le texte OU domaine propre cité) / non visible — `visible ÷ totalResults` est la **Visibility** du dashboard |
| `mentions` | Réponses nommant la marque dans le texte — `mentions ÷ totalResults` est le **Mention Rate** |
| `cited` | Réponses citant le domaine propre (ou un alias de domaine) comme source — `cited ÷ totalResults` est le **Citation Rate**. `null` lorsque le jour provient d'un agrégat (rollup) qui ne contient pas les citations |
| `mentionOrder` | Position ordinale moyenne parmi les marques nommées (1 = nommée en premier ; le KPI **Position** du dashboard), `null` lorsque la marque n'a pas été nommée |
| `position` | Profondeur de mention — à quelle profondeur du texte de la réponse la mention apparaît (0 = tout en haut) |
| `sentiment` | Score de sentiment moyen (0–100) sur les réponses visibles |
| `uniquePrompts` | Prompts distincts avec au moins une réponse ce jour-là |

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Fenêtre glissante lorsque `startDate` / `endDate` ne sont pas utilisés.
</ParamField>

<ParamField query="startDate" type="string">
  Date ISO `YYYY-MM-DD` (à utiliser avec `endDate`).
</ParamField>

<ParamField query="endDate" type="string">
  Date ISO `YYYY-MM-DD` (à utiliser avec `startDate`).
</ParamField>

<ParamField query="model" type="string">
  Filtre sur un seul modèle.
</ParamField>

<ParamField query="language" type="string">
  Filtre par langue des prompts.
</ParamField>

<ParamField query="tags" type="string">
  Tableau JSON ou Tags séparés par des virgules.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries?timeframe=14d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "14d", "model": "chatgpt"},
)
series = r.json()["data"]["chartData"]
last = series[-1]
print(last["date"], last["visible"] / last["totalResults"], last["mentions"], last["cited"])
```
