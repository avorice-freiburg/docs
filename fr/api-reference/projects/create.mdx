---
title: Créer un projet
api: POST /v1/projects
---

Crée un nouveau projet. Finseo suivra la visibilité IA de la marque associée à ce projet sur ChatGPT, Claude, Perplexity et les modèles configurés.


<ParamField body="name" type="string" required>
  Nom d'affichage (1–200 caractères).
</ParamField>

<ParamField body="language" type="string" required>
  Langue de l'analyse de marque et des prompts générés (insensible à la casse).
  Valeurs acceptées : `en`, `de`, `fr`, `es`, `it`, `nl`, `pt`, `pl`, `sv`, `da`, `tr`, `ja`,
  `no`, `fi`, `cs`, `ru`, `zh`, `zh-tw`, `ko`, `hi`, `ar`, `he`.
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canonique du site ; utilisée pour déduire `domain` en cas d'omission.
</ParamField>

<ParamField body="domain" type="string">
  Domaine racine (p. ex. `finseo.ai`). Facultatif si `websiteUrl` est fourni.
</ParamField>

<ParamField body="description" type="string">
  Notes facultatives (500 caractères max).
</ParamField>

<ParamField body="isPitch" type="boolean">
  Crée un **projet pitch** sans frais de projet, limité à 50 prompts et mis
  automatiquement en pause à la fin de la période. Idéal pour les analyses
  ponctuelles de prospects par les agents commerciaux. Les slots sont limités
  selon l'offre agence (250 avec Agency Starter, 500 avec Agency Studio).
</ParamField>

<ParamField body="pitchDurationDays" type="number" default="14">
  Durée du pitch en jours : `1` (exécution unique), `7` ou `14`. Ignoré sauf si
  `isPitch` vaut `true`. Convertissez un pitch gagné avec
  [Mettre à jour le projet](/api-reference/projects/update) et `convertFromPitch`.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks"
  }'
```

```python Python
import requests

payload = {
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks",
}
r = requests.post(
    "https://api.finseo.ai/v1/projects",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
created = r.json()["data"]
print(created["id"])
```
