---
title: Lister les projets
api: GET /v1/projects
---

Renvoie la liste des projets accessibles avec votre clé API. Les projets représentent les marques ou domaines suivis dans Finseo pour la visibilité IA sur ChatGPT, Claude, Perplexity et d'autres modèles.

Chaque projet contient `isPitch`. Les projets pitch contiennent aussi `pitchDurationDays` (1, 7 ou 14) et `pitchExpiredAt` (`null` tant que la période reste ouverte), afin qu'un agent sache précisément combien de temps le pitch continue.


<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.finseo.ai/v1/projects \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

response = requests.get(
    "https://api.finseo.ai/v1/projects",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
)
projects = response.json()["data"]
for p in projects:
    print(p["name"], p["id"])
```

</RequestExample>
