---
title: Mettre à jour un projet
api: PUT /v1/projects/{projectId}
---

Met à jour un projet existant. N'envoyez que les champs que vous souhaitez modifier.

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>


<ParamField body="name" type="string">
  Nouveau nom d'affichage (1–200 caractères).
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canonique mise à jour.
</ParamField>

<ParamField body="domain" type="string">
  Domaine racine mis à jour.
</ParamField>

<ParamField body="convertFromPitch" type="boolean">
  Définissez ce champ sur `true` pour convertir un projet pitch en projet client complet, par exemple après avoir remporté le prospect. La conversion vérifie qu'un slot client est disponible et que le budget de réponses couvre les prompts, puis réactive les prompts suspendus. Elle échoue si le projet n'est pas un pitch.
</ParamField>

<ParamField body="description" type="string">
  Description mise à jour (500 caractères max).
</ParamField>

<ParamField body="models" type="array">
  Modèles IA sur lesquels les prompts du projet s'exécutent — l'équivalent API
  des **Model Settings** du dashboard. Remplace l'ensemble complet et
  resynchronise chaque prompt du projet (`syncedPromptCount` dans la réponse) ;
  la prochaine exécution planifiée utilise le nouvel ensemble. Valeurs
  acceptées : `chatgpt`, `perplexity`, `ai_overview`, `google_ai_mode`,
  `copilot`, `claude`, `gemini`, `grok`, `mistral`, `deepseek`.

  Les mêmes limites s'appliquent que dans le dashboard : le plafond de modèles
  de votre offre (3 sur les offres Brand sauf relèvement), le budget de prompts
  sur les offres Brand et la tranche de réponses IA incluse dans les offres
  Agency. Sur l'offre Agency la plus élevée, l'appel réussit et renvoie un
  `meteredNotice` lorsque la projection dépasse les réponses incluses — le
  dépassement est facturé en supplément, exactement comme dans l'interface.
</ParamField>

## Erreurs

Les dépassements de limites renvoient `403` avec `error.code = "FORBIDDEN"` et
un `error.details.reason` lisible par machine :

| `details.reason` | Signification |
| --- | --- |
| `model_limit` | Plus de modèles que votre offre ne le permet (`details.limit`). |
| `model_not_available` | Moteur non disponible dans votre offre (`details.models`). |
| `prompt_budget_exceeded` | Offre Brand : le nouvel ensemble de modèles dépasserait le budget de prompts (`promptLimit`, `slotsUsed`, `projectedSlots`). |
| `agency_limit` | Agency : les réponses mensuelles projetées dépassent la tranche incluse et une offre supérieure existe (`package`, `nextPackage`, `includedResults`, `projectedMonthlyAnswers`) — ou, pour `convertFromPitch`, aucun slot client n'est libre (`details.limit = "projects"`). |

```bash Définir les modèles
curl --request PUT \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b \
  --header "Authorization: Bearer $FINSEO_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{"models": ["chatgpt", "perplexity", "ai_overview", "claude"]}'
```

```python Python
import requests

project_id = "67a1c2d3e4f5061728394a5b"
r = requests.put(
    f"https://api.finseo.ai/v1/projects/{project_id}",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json={"models": ["chatgpt", "perplexity", "ai_overview", "claude"]},
)
if r.status_code == 403:
    print("blocked:", r.json()["error"]["details"]["reason"])
else:
    print(r.json()["data"]["models"])
```
