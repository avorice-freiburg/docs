---
title: Créer un prompt
api: POST /v1/projects/{projectId}/prompts
---

Ajoute un nouveau prompt de Tracking à un projet. Finseo exécutera ce prompt sur les modèles spécifiés et enregistrera la visibilité de votre marque par rapport aux concurrents sur ChatGPT, Claude et Perplexity.

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>


<ParamField body="prompt" type="string" required>
  Texte du prompt (1–500 caractères).
</ParamField>

<ParamField body="models" type="array">
  Identifiants de modèles ; valeur par défaut `["chatgpt", "perplexity", "ai_overview"]`.
</ParamField>

<ParamField body="language" type="string" default="en">
  La valeur par défaut est `en`. La langue n'est **pas** héritée du projet ; indiquez-la explicitement pour les projets non anglophones.
</ParamField>

<ParamField body="tags" type="array">
  Tags facultatifs (chaînes) pour le filtrage dans les analyses.
</ParamField>

<Note>
  Les projets pitch (`isPitch: true`) sont limités à **50 prompts**. L'ajout de prompts à un pitch expiré est refusé ; convertissez-le d'abord en projet client via [Mettre à jour le projet](/api-reference/projects/update).
</Note>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "models": ["chatgpt", "claude", "perplexity"],
    "language": "en",
    "tags": ["comparison", "Finseo"]
  }'
```

```python Python
import requests

payload = {
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "models": ["chatgpt", "claude", "perplexity"],
    "language": "en",
    "tags": ["comparison", "Finseo"],
}
r = requests.post(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
print(r.json()["data"])
```
