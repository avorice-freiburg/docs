---
title: Lister les prompts
api: GET /v1/projects/{projectId}/prompts
---

Liste les prompts suivis d'un projet avec la visibilité, le nombre de Mentions, les citations et le Sentiment pour la période sélectionnée. Finseo évalue ces prompts sur ChatGPT, Claude, Perplexity et d'autres modèles.

Par prompt, tous les décomptes se rapportent aux réponses IA de la période sélectionnée (`resultCount` ; voir [KPIs expliqués](/fr/getting-started/kpis)) :

- `isVisible` — la marque a été visible dans au moins une réponse : nommée dans le texte de la réponse OU le domaine propre cité comme source
- `totalMentions` / `mentionRate` — réponses nommant la marque dans le texte, et ce décompte en % de `resultCount` (**Mention Rate**)
- `ownDomainCitations` / `citationRate` — réponses citant le domaine propre (ou un alias de domaine configuré) comme source, et ce décompte en % de `resultCount` (**Citation Rate**)

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Durée de la fenêtre glissante, p. ex. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Filtre les résultats sur un seul modèle (p. ex. `chatgpt`).
</ParamField>

<ParamField query="language" type="string">
  Filtre par code de langue ISO (p. ex. `en`, `de`).
</ParamField>

<ParamField query="tags" type="string">
  Chaîne au format tableau JSON ou noms de Tags séparés par des virgules pour filtrer les prompts.
</ParamField>

<ParamField query="search" type="string">
  Correspondance de sous-chaîne insensible à la casse sur le texte du prompt.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Numéro de page (à partir de 1).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Taille de page (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts?timeframe=30d&limit=10&page=1' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

params = {"timeframe": "30d", "limit": 10, "page": 1, "search": "Finseo"}
r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params=params,
)
body = r.json()["data"]
first = body["prompts"][0]
print(body["totalCount"], first["prompt"], first["mentionRate"], first["citationRate"])
```
