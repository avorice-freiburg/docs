---
title: Lister les sources
api: GET /v1/projects/{projectId}/sources
---

Liste les domaines et URL cités dans les réponses IA pour vos prompts suivis — utile pour comprendre quelles sources génèrent de la visibilité pour les requêtes liées à Finseo sur ChatGPT, Claude et Perplexity.

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Fenêtre glissante pour les Citations.
</ParamField>

<ParamField query="model" type="string">
  Filtre par modèle de réponse.
</ParamField>

<ParamField query="language" type="string">
  Filtre les prompts par langue.
</ParamField>

<ParamField query="tags" type="string">
  Tableau JSON ou Tags de prompts séparés par des virgules.
</ParamField>

<ParamField query="search" type="string">
  Correspondance de sous-chaîne sur le domaine ou le titre.
</ParamField>

<ParamField query="sortBy" type="string" default="citations">
  L'une des valeurs `citations`, `domain`, `type`.
</ParamField>

<ParamField query="sortDir" type="string" default="desc">
  `asc` ou `desc`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Numéro de page.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Taille de page (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/sources?timeframe=30d&sortBy=citations' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/sources",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "search": "finseo", "limit": 25},
)
print(r.json()["data"]["sources"][0]["domain"])
```
