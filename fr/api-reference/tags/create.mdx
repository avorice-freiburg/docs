---
title: Appliquer un tag aux prompts
api: POST /v1/projects/{projectId}/tags
---

Ajoute un tag à un ou plusieurs prompts. Le tag est fusionné avec les Tags existants du prompt, ce qui vous permet d'organiser vos cohortes de Tracking Finseo sans remplacer les autres libellés.

<ParamField path="projectId" type="string" required>
  Identifiant du projet.
</ParamField>


<ParamField body="name" type="string" required>
  Nom du tag (1–100 caractères).
</ParamField>

<ParamField body="promptIds" type="array" required>
  Liste non vide d'UUID de prompts à mettre à jour.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/tags \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Q1-2026",
    "promptIds": ["a1b2c3d4-e5f6-7890-abcd-ef1234567890", "b2c3d4e5-f6a7-8901-bcde-f12345678901"]
  }'
```

```python Python
import requests

payload = {
    "name": "Q1-2026",
    "promptIds": [
        "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "b2c3d4e5-f6a7-8901-bcde-f12345678901",
    ],
}
r = requests.post(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/tags",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
print(r.json()["data"])
```

</RequestExample>

<ResponseExample>

```json
{
  "data": {
    "tag": "Q1-2026",
    "appliedTo": 2
  }
}
```

</ResponseExample>
