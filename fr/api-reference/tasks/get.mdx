---
title: Obtenir une Task
api: GET /v1/projects/{projectId}/tasks/{taskId}
description: Lis une task d'optimisation complète — description, plan d'action étape par étape, les preuves à l'origine de la task et le content plan structuré pour les tasks de contenu.
---

Renvoie la task complète : la description intégrale, un plan d'action étape par étape, les preuves (données et prompts ou sources concernés) à l'origine de la task et — pour les tasks de contenu — un `contentPlan` structuré décrivant la page cible, le template et les prompts que le contenu doit couvrir.

Récupère le `taskId` depuis [Lister les Tasks](/fr/api-reference/tasks/list) (champ `id`).

<ParamField path="projectId" type="string" required>L'ID du projet</ParamField>
<ParamField path="taskId" type="string" required>L'ID de la task (UUID) depuis Lister les Tasks</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/tasks/05ba7f64-9c1e-4f2a-8d3b-1a2b3c4d5e6f' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/tasks/{task_id}",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)
task = response.json()["data"]

print(task["title"])
for i, step in enumerate(task["steps"], 1):
    print(f"{i}. {step}")
```

```javascript Node.js
const res = await fetch(
  `https://api.finseo.ai/v1/projects/${projectId}/tasks/${taskId}`,
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const { data: task } = await res.json();
console.log(task.title, task.steps);
```
