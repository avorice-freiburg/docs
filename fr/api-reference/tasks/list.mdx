---
title: Lister les Tasks
api: GET /v1/projects/{projectId}/tasks
description: Liste les tasks d'optimisation générées par IA d'un projet — des to-dos concrets et priorisés dérivés de tes données de visibilité, triés par priority score.
---

Les tasks d'optimisation sont générées automatiquement à partir des données de visibilité IA de ton projet — par exemple corriger des erreurs de crawl rencontrées par les bots IA, répondre à des threads communautaires à fort potentiel, combler des gaps face aux concurrents ou retravailler du contenu faible. Cet endpoint renvoie les mêmes tasks que la page Tasks du dashboard Finseo.

Les lignes sont compactes et triées par `priorityScore` (impact pondéré par l'effort — plus il est élevé, plus la task est prioritaire). Utilise [Obtenir une Task](/fr/api-reference/tasks/get) avec l'`id` d'une task pour la description complète, le plan étape par étape et les preuves.

<Note>Le module Tasks est actuellement en bêta. Les tasks sont en lecture seule via l'API — les changements de statut se font dans le dashboard.</Note>

<ParamField path="projectId" type="string" required>L'ID du projet</ParamField>
<ParamField query="status" type="string" default="open">Statuts séparés par des virgules — `open`, `in_progress`, `done`, `dismissed` ou `all`</ParamField>
<ParamField query="category" type="string">Filtrer par catégorie — `technical`, `visibility`, `content`, `offsite`, `reputation`, `competitor` ou `setup`</ParamField>
<ParamField query="minImpact" type="integer">Ne renvoyer que les tasks avec au moins ce score d'impact (1–10)</ParamField>
<ParamField query="page" type="integer" default="1">Numéro de page</ParamField>
<ParamField query="limit" type="integer" default="50">Résultats par page (max 200)</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/tasks?status=open&limit=10' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/tasks",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"status": "open", "limit": 10}
)
tasks = response.json()["data"]["tasks"]

for t in tasks:
    print(f"[{t['priorityScore']}] {t['category']}: {t['title']}")
```

```javascript Node.js
const res = await fetch(
  `https://api.finseo.ai/v1/projects/${projectId}/tasks?status=open`,
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const { data } = await res.json();
data.tasks.forEach(t => console.log(t.priorityScore, t.title));
```
