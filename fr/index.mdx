# Finseo API

Suis la manière dont ta marque apparaît dans ChatGPT, Claude, Perplexity et d'autres plateformes IA. La Finseo Customer API te permet de récupérer des métriques de visibilité, de gérer des prompts, d'analyser des concurrents et d'exporter des données.

## Base URL

```
https://api.finseo.ai/v1
```

## Exemple rapide

<CodeGroup>

```bash cURL
curl --request GET \
  --url https://api.finseo.ai/v1/projects/YOUR_PROJECT_ID/metrics?timeframe=30d \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

headers = {"Authorization": "Bearer YOUR_API_KEY"}
response = requests.get(
    "https://api.finseo.ai/v1/projects/YOUR_PROJECT_ID/metrics",
    headers=headers,
    params={"timeframe": "30d"}
)

data = response.json()["data"]
print(f"Visibility Rate: {data['current']['visibilityRate']}%")
print(f"Mentions: {data['current']['mentions']}")
print(f"Change: {data['changes']['visibilityRateChange']:+.1f}%")
```

```javascript Node.js
const response = await fetch(
  "https://api.finseo.ai/v1/projects/YOUR_PROJECT_ID/metrics?timeframe=30d",
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);

const { data } = await response.json();
console.log(`Visibility: ${data.current.visibilityRate}%`);
console.log(`Mentions: ${data.current.mentions}`);
```

## Format de réponse

Tous les endpoints renvoient une enveloppe JSON cohérente :

| Champ | Description |
|-------|-------------|
| `data` | La payload de la réponse |
| `meta` | Infos de pagination (le cas échéant) |
| `error` | Détails de l'erreur (uniquement en cas d'échec) |

## Codes d'erreur

| Code | Status | Description |
|------|--------|-------------|
| `UNAUTHORIZED` | 401 | Clé API manquante ou invalide |
| `FORBIDDEN` | 403 | Scopes insuffisants |
| `NOT_FOUND` | 404 | Ressource introuvable |
| `VALIDATION_ERROR` | 400 | Paramètres invalides |
| `RATE_LIMIT_EXCEEDED` | 429 | Trop de requêtes |
| `PROJECT_ACCESS_DENIED` | 403 | La clé API ne peut pas accéder à ce projet |
| `INTERNAL_ERROR` | 500 | Erreur serveur |
