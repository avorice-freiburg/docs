## Intégrations d'attribution

Les intégrations d'attribution utilisent soit :

- Une URL de webhook de projet pour les formulaires et les CRM.
- La Customer API pour les outils d'automatisation tels que Zapier, Make ou n8n.

Les URLs de webhook ressemblent à ceci :

```text
https://app.finseo.ai/api/attribution/webhook/PROJECT_ID?source=SOURCE&token=WEBHOOK_TOKEN
```

Le paramètre `source` aide Finseo à choisir le bon parser. Le `token` protège l'endpoint.

## Sources d'attribution prises en charge

| Source | Voie recommandée | Notes |
| --- | --- | --- |
| HubSpot | Webhook de workflow | Nécessite une action de workflow HubSpot qui envoie un webhook. Data Hub Pro/Enterprise peut être requis pour les actions de webhook natives. |
| Salesforce | Flow HTTP Callout | Utilise le JSON depuis Flow Builder. Les Outbound Messages natifs de Salesforce envoient du XML et ne sont pas pris en charge. |
| Typeform | Webhook natif | Ajoute une question « Comment nous avez-vous trouvés ? » et envoie toutes les réponses à Finseo. |
| Jotform | Webhook natif | Finseo gère les payloads multipart/form-data et `rawRequest` de Jotform. |
| Gravity Forms | Webhooks Add-On | Envoie du JSON et mappe le champ d'attribution si besoin. |
| Formstack | Webhook natif | Envoie les soumissions de formulaire en JSON. |
| Attio | Webhook natif | Envoie des payloads de création/mise à jour d'enregistrements avec des champs personnalisés. |
| Pipedrive | Webhook d'automation | Envoie les champs de deal et de personne depuis les automations. |
| Close | Webhook natif | Envoie des events de lead ou de contact. |
| Calendly | Abonnement webhook | Envoie les réponses des invités issues des questions de réservation. |
| Intercom | Webhook natif | Envoie des events de contact ou de conversation avec des attributs personnalisés. |
| Zapier / Make / n8n | Requête HTTP | Utilise la Finseo API ou un webhook générique et mappe les champs manuellement. |

## HubSpot

1. Dans Finseo, ouvre **Integrations** et sélectionne **HubSpot**.
2. Copie l'URL du webhook.
3. Dans HubSpot, va dans **Automations -> Workflows**.
4. Crée un workflow déclenché par une soumission de formulaire ou une création de contact.
5. Ajoute une action **Send webhook**.
6. Colle l'URL du webhook Finseo.
7. Soumets un lead de test et vérifie **Attribution** dans Finseo.

Finseo recherche des champs courants tels que `email`, `firstname`, `lastname`, `how_did_you_find_us`, `deal_amount` et `amount`.

## Salesforce

Utilise **Flow HTTP Callout**, pas les Outbound Messages natifs.

```json
{
  "LeadSource": "ChatGPT",
  "Email": "buyer@example.com",
  "Name": "Alex Buyer",
  "Id": "00Qxx0000012345",
  "Amount": 8500,
  "CurrencyIsoCode": "USD"
}
```

Finseo mappe `LeadSource` vers le canal d'attribution, `Email` vers l'e-mail du répondant, `Name` vers le nom du répondant, `Amount` vers la valeur du deal et `CurrencyIsoCode` vers la devise.

## Typeform et Jotform

Pour les outils de formulaire, ajoute une question comme :

```text
How did you find us?
```

Bonnes options de réponse :

- ChatGPT
- Perplexity
- Claude
- Google
- Réseaux sociaux
- Ami ou collègue
- Ads
- Autre

Ajoute ensuite l'URL du webhook Finseo dans les paramètres de webhook du formulaire. Finseo reçoit la soumission complète et extrait la réponse d'attribution.

## Zapier, Make et n8n

Utilise ces outils quand ton outil source n'a pas de webhook natif ou quand tu veux transformer des champs avant de les envoyer à Finseo.

```json
{
  "channelId": "{{how_did_you_find_us}}",
  "respondentEmail": "{{email}}",
  "respondentName": "{{name}}",
  "respondentExternalId": "{{crm_id}}",
  "dealValue": "{{amount}}",
  "dealCurrency": "{{currency}}",
  "metadata": {
    "source_tool": "zapier",
    "form": "{{form_name}}"
  }
}
```

Tu peux l'envoyer soit vers l'URL du webhook de projet, soit vers la [Create Attribution API](/api-reference/attribution/submit).

## Mapping des champs

Si un outil envoie des champs avec des noms inhabituels, envoie d'abord un payload de test. Finseo crée un workflow Attribution à partir de la structure entrante. Ouvre **Attribution -> Workflows** et mappe les champs vers :

- Réponse d'attribution
- E-mail
- Nom
- Valeur du deal
- Devise du deal
- ID de formulaire

Utilise des règles quand un champ source doit être traduit. Par exemple, mappe `utm_source contains chatgpt` vers `AI Search`.

## Checklist de test

- Envoie une soumission de test depuis l'outil source.
- Confirme que la réponse apparaît dans **Attribution**.
- Confirme que la catégorie de canal est correcte, surtout pour les sources IA.
- Ajoute `dealValue` et `dealCurrency` si tu veux du reporting de revenu.
- Ajoute un `respondentExternalId` stable tel qu'un ID de commande, un ID de lead ou un ID de deal.
- Garde des noms de champs cohérents à travers les marchés et les pays.
