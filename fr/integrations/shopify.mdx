# Shopify

<Note>
L'intégration Shopify arrive **bientôt**. Cette page décrit les fonctionnalités prévues.
</Note>

Connecte ta boutique Shopify pour laisser l'agent Finseo optimiser les titres SEO produits, les descriptions, les données structurées (schémas JSON-LD), le contenu des pages et les redirections d'URL — via des commandes en langage naturel comme « Optimise les titres SEO de mes 5 meilleurs produits ».

## Comment ça fonctionnera

1. Clique sur **Connect** sur la carte Shopify sous **Integrations** et saisis l'URL de ta boutique (par ex. `mystore.myshopify.com`).
2. Tu seras redirigé vers Shopify pour autoriser Finseo via OAuth — aucune clé API à copier.
3. Une fois autorisé, l'agent accède à la Shopify Admin API et peut lire et modifier les produits, pages, collections, données structurées et redirections.
4. Chaque modification nécessite ta confirmation avant d'être appliquée.
