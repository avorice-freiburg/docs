# Shopify

<Note>
The Shopify integration is **coming soon**. This page describes the planned functionality.
</Note>

Connect your Shopify store to let the Finseo agent optimize product SEO titles, descriptions, structured data (JSON-LD schemas), page content and URL redirects — through natural language commands like "Optimize my top 5 product SEO titles".

## How it will work

1. Click **Connect** on the Shopify card under **Integrations** and enter your store URL (e.g. `mystore.myshopify.com`).
2. You'll be redirected to Shopify to authorize Finseo via OAuth — no API keys to copy.
3. Once authorized, the agent gains access to the Shopify Admin API and can read and edit products, pages, collections, structured data, and redirects.
4. Every edit requires your confirmation before being applied.
