---
title: Elenca i concorrenti
api: GET /v1/projects/{projectId}/competitors
---

Restituisce i concorrenti in classifica per visibilità AI: visibilità, mention rate, citation rate, Mentions, Share of Voice, posizione e Sentiment. Usa questo Endpoint per vedere come Finseo si posiziona rispetto agli altri brand nelle risposte di ChatGPT, Claude e Perplexity.

Per ogni concorrente vengono restituiti tre tassi di presenza, tutti come quota di `totalResults` (vedi [KPI e metriche](/it/getting-started/kpis)):

- `visibilityRate` — **Visibility**: % di risposte in cui il brand è visibile, cioè nominato nel testo della risposta O con il proprio dominio citato come fonte (la colonna "Visibility" della dashboard; `visibleResults` è il conteggio). `visibilityIsMentionOnly: true` segnala le righe in cui la componente citazioni non è stata risolta e il valore coincide con il tasso basato sulle sole menzioni.
- `mentionRate` — **Mention Rate**: % di risposte che nominano il brand nel testo (`totalMentions` è il conteggio).
- `citationRate` — **Citation Rate**: % di risposte che citano il dominio del brand come fonte (`totalCitations` è il conteggio); `null` quando le citazioni non sono state risolte per il brand.

Una risposta può contare sia in `mentionRate` sia in `citationRate`, quindi `visibilityRate ≤ mentionRate + citationRate`.

Per ogni concorrente vengono restituite due metriche di posizione:

- `avgMentionOrder` — il KPI ordinale **Position**: rango medio tra tutti i brand nominati in una risposta (1 = nominato per primo, più basso è meglio). È il valore in stile `#2.3` mostrato nella pagina concorrenti della dashboard.
- `averagePosition` — **Mention Depth**: quanto in profondità nel *testo* della risposta compare la menzione (0% = all'inizio). Non è una posizione in classifica; mantiene questo nome per retrocompatibilità.

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Finestra di analisi, es. `7d`, `30d`.
</ParamField>

<ParamField query="model" type="string">
  Filtra i risultati di Tracking su un singolo modello.
</ParamField>

<ParamField query="language" type="string">
  Filtra i Prompt per lingua.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON o elenco di Tag dei Prompt separati da virgola.
</ParamField>

<ParamField query="search" type="string">
  Filtra per sottostringa del nome o del dominio del concorrente.
</ParamField>

<ParamField query="sortBy" type="string" default="visibility">
  Uno tra `visibility` (nominato O citato), `mentions`, `position`, `sentiment`, `name`.
</ParamField>

<ParamField query="sortDir" type="string" default="desc">
  `asc` o `desc`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Numero di pagina.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Dimensione della pagina (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors?timeframe=30d&sortBy=mentions&limit=20' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "sortBy": "visibility", "limit": 20},
)
competitors = r.json()["data"]["competitors"]
print([c["name"] for c in competitors if c["isUserBrand"]])
```
