---
title: Esporta i dati del progetto
api: GET /v1/projects/{projectId}/export
---

Esporta i Prompt con i risultati di Tracking annidati per il periodo selezionato. Pensato per analisi offline, strumenti di BI o backup dei dati di visibilità AI di Finseo da ChatGPT, Claude, Perplexity e altri modelli.

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Finestra mobile dei risultati da includere (max 1000 Prompt; risultati limitati dall'intervallo di date).
</ParamField>

<ParamField query="model" type="string">
  Interpretato tramite lo schema condiviso; l'handler di export può includere tutti i modelli nei risultati.
</ParamField>

<ParamField query="language" type="string">
  Interpretato tramite lo schema condiviso.
</ParamField>

<ParamField query="tags" type="string">
  Interpretato tramite lo schema condiviso.
</ParamField>

<ParamField query="page" type="integer">
  Interpretato tramite lo schema condiviso.
</ParamField>

<ParamField query="limit" type="integer">
  Interpretato tramite lo schema condiviso.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/export?timeframe=30d' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/export",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d"},
)
export_payload = r.json()["data"]
print(export_payload["timeframeDays"], len(export_payload["prompts"]))
```
