---
title: Elenca i Fan-out
api: GET /v1/projects/{projectId}/fanouts
description: Ottieni le query Fan-out AI (le sotto-query correlate che i modelli AI hanno generato mentre rispondevano ai tuoi Prompt tracciati), aggregate e ordinate per frequenza.
---

Le query Fan-out sono sotto-query correlate che i modelli AI (ChatGPT, Claude, Perplexity, ecc.) generano internamente mentre rispondono ai tuoi Prompt tracciati. Questo Endpoint le aggrega su tutti i risultati di Tracking in una finestra temporale e le restituisce ordinate per numero di occorrenze.

Sono gli stessi dati mostrati nella pagina Query Fan-outs della Dashboard di Finseo.

<ParamField path="projectId" type="string" required>L'ID del progetto</ParamField>
<ParamField query="timeframe" type="string" default="90d">Finestra temporale — `7d`, `30d`, `90d`, `365d`, oppure `all` per ottenere tutti i Fan-out di sempre</ParamField>
<ParamField query="startDate" type="string">Data di inizio personalizzata (YYYY-MM-DD), ha la precedenza sulla timeframe</ParamField>
<ParamField query="endDate" type="string">Data di fine personalizzata (YYYY-MM-DD), ha la precedenza sulla timeframe</ParamField>
<ParamField query="tags" type="string">Tag separati da virgola per filtrare i Prompt di origine</ParamField>
<ParamField query="page" type="integer" default="1">Numero di pagina</ParamField>
<ParamField query="limit" type="integer" default="50">Risultati per pagina (max 500)</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/fanouts?timeframe=30d&limit=20' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/fanouts",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"timeframe": "30d", "limit": 20}
)
fanouts = response.json()["data"]["fanouts"]

for f in fanouts:
    print(f"{f['query']} — {f['count']} occurrences across {f['promptCount']} prompts")
```

```javascript Node.js
const res = await fetch(
  `https://api.finseo.ai/v1/projects/${projectId}/fanouts?timeframe=30d`,
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const { data } = await res.json();
data.fanouts.forEach(f => console.log(f.query, f.count));
```
