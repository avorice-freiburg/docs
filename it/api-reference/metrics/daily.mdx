---
title: Metriche del progetto (riepilogo)
api: GET /v1/projects/{projectId}/metrics
---

Restituisce le metriche aggregate di visibilità AI per il periodo corrente confrontate con il periodo precedente di pari durata. Usa questo Endpoint per Dashboard e KPI sulla visibilità di Finseo su ChatGPT, Claude, Perplexity e gli altri modelli tracciati.

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Finestra mobile, es. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Limita le metriche a un singolo modello.
</ParamField>

<ParamField query="language" type="string">
  Filtra per lingua del Prompt.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON o Tag separati da virgola per filtrare i Prompt.
</ParamField>

<ParamField query="page" type="integer">
  Incluso per il parsing condiviso della query; le metriche ignorano la paginazione.
</ParamField>

<ParamField query="limit" type="integer">
  Incluso per il parsing condiviso della query; le metriche ignorano la paginazione.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics?timeframe=30d' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "language": "en"},
)
metrics = r.json()["data"]
print(metrics["current"]["visibilityRate"], metrics["changes"]["visibilityRateChange"])
```
