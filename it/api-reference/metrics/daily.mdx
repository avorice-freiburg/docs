---
title: Metriche del progetto (riepilogo)
api: GET /v1/projects/{projectId}/metrics
---

Restituisce le metriche aggregate di visibilità AI per il periodo corrente confrontate con il periodo precedente di pari durata. Usa questo Endpoint per Dashboard e KPI sulla visibilità di Finseo su ChatGPT, Claude, Perplexity e gli altri modelli tracciati.

La risposta riporta il periodo corrente in `today` e il periodo precedente in `yesterday` (nomi legacy — ogni blocco aggrega l'intero periodo, `date` è la data di fine del periodo). Tutti i tassi condividono lo stesso denominatore, `totalResponses` (vedi [KPI e metriche](/it/getting-started/kpis)):

| Campo | Significato |
| --- | --- |
| `responseVisibilityRate` | **Visibility** — % di risposte in cui il brand è visibile: nominato nel testo O dominio proprio citato come fonte (il KPI "Visibility" della dashboard) |
| `mentionRate` | **Mention Rate** — % di risposte che nominano il brand nel testo della risposta |
| `citationRate` | **Citation Rate** — % di risposte che citano il dominio proprio (o un alias di dominio configurato) come fonte |
| `mentions` / `cited` | Conteggi assoluti dietro Mention Rate e Citation Rate (risposte, ognuna contata una volta) |
| `visibilityRate` | Copertura dei Prompt — % di Prompt tracciati con almeno una risposta visibile (un numero diverso, di solito più alto) |
| `visible` / `notVisible` | Numero di Prompt con / senza una risposta visibile |
| `position` | Profondità di menzione — quanto in profondità nel testo della risposta compare la menzione (0 = inizio), non una posizione in classifica |

Una risposta può contare sia in `mentionRate` sia in `citationRate`, quindi `responseVisibilityRate ≤ mentionRate + citationRate`.

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Finestra mobile, es. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Limita le metriche a un singolo modello.
</ParamField>

<ParamField query="language" type="string">
  Filtra per lingua del Prompt.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON o Tag separati da virgola per filtrare i Prompt.
</ParamField>

<ParamField query="page" type="integer">
  Incluso per il parsing condiviso della query; le metriche ignorano la paginazione.
</ParamField>

<ParamField query="limit" type="integer">
  Incluso per il parsing condiviso della query; le metriche ignorano la paginazione.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics?timeframe=30d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "language": "en"},
)
metrics = r.json()["data"]
cur, chg = metrics["today"], metrics["changes"]
print(cur["responseVisibilityRate"], cur["mentionRate"], cur["citationRate"], chg["responseVisibilityRateChange"])
```
