---
title: Serie temporale delle metriche
api: GET /v1/projects/{projectId}/metrics/timeseries
---

Restituisce le metriche giornaliere di visibilità AI, pronte per i grafici. Ogni riga in `data.chartData` corrisponde a un giorno di calendario all'interno della finestra derivata da `timeframe`, oppure tra `startDate` / `endDate` quando entrambi sono presenti. Ideale per le linee di tendenza di Finseo su ChatGPT, Claude e Perplexity.

Campi per giorno (tutti i conteggi sono risposte AI di quel giorno; vedi [KPI e metriche](/it/getting-started/kpis)):

| Campo | Significato |
| --- | --- |
| `totalResults` | Risposte AI analizzate in quel giorno |
| `visible` / `notVisible` | Risposte in cui il brand è visibile (nominato nel testo O dominio proprio citato) / non visibile — `visible ÷ totalResults` è la **Visibility** della dashboard |
| `mentions` | Risposte che nominano il brand nel testo — `mentions ÷ totalResults` è il **Mention Rate** |
| `cited` | Risposte che citano il dominio proprio (o un alias di dominio) come fonte — `cited ÷ totalResults` è il **Citation Rate**. `null` quando il giorno proviene da un rollup che non include le citazioni |
| `mentionOrder` | Posizione ordinale media tra i brand nominati (1 = nominato per primo; il KPI **Position** della dashboard), `null` quando il brand non è stato nominato |
| `position` | Profondità di menzione — quanto in profondità nel testo della risposta compare la menzione (0 = inizio) |
| `sentiment` | Punteggio medio di sentiment (0–100) sulle risposte visibili |
| `uniquePrompts` | Prompt distinti con almeno una risposta in quel giorno |

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Finestra mobile quando `startDate` / `endDate` non vengono usati.
</ParamField>

<ParamField query="startDate" type="string">
  Data ISO `YYYY-MM-DD` (da usare con `endDate`).
</ParamField>

<ParamField query="endDate" type="string">
  Data ISO `YYYY-MM-DD` (da usare con `startDate`).
</ParamField>

<ParamField query="model" type="string">
  Filtra su un singolo modello.
</ParamField>

<ParamField query="language" type="string">
  Filtro per lingua del Prompt.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON o Tag separati da virgola.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries?timeframe=14d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "14d", "model": "chatgpt"},
)
series = r.json()["data"]["chartData"]
last = series[-1]
print(last["date"], last["visible"] / last["totalResults"], last["mentions"], last["cited"])
```
