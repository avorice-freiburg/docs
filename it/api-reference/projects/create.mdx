---
title: Crea un progetto
api: POST /v1/projects
---

Crea un nuovo progetto. Finseo traccerà la visibilità AI del brand associato a questo progetto su ChatGPT, Claude, Perplexity e i modelli configurati.


<ParamField body="name" type="string" required>
  Nome visualizzato (1–200 caratteri).
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canonico del sito; usato per dedurre `domain` quando questo viene omesso.
</ParamField>

<ParamField body="domain" type="string">
  Dominio radice (es. `finseo.ai`). Facoltativo se fornisci `websiteUrl`.
</ParamField>

<ParamField body="description" type="string">
  Note facoltative (max 500 caratteri).
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "description": "Experimental prompts and benchmarks"
  }'
```

```python Python
import requests

payload = {
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "description": "Experimental prompts and benchmarks",
}
r = requests.post(
    "https://api.finseo.ai/v1/projects",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
created = r.json()["data"]
print(created["id"])
```
