---
title: Aggiorna un progetto
api: PUT /v1/projects/{projectId}
---

Aggiorna un progetto esistente. Invia solo i campi che vuoi modificare.

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>


<ParamField body="name" type="string">
  Nuovo nome visualizzato (1–200 caratteri).
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canonico aggiornato.
</ParamField>

<ParamField body="domain" type="string">
  Dominio radice aggiornato.
</ParamField>

<ParamField body="convertFromPitch" type="boolean">
  Imposta su `true` per convertire un progetto pitch in un progetto cliente completo, ad esempio dopo aver acquisito il prospect. La conversione verifica uno slot cliente libero e che il budget di risposte copra i prompt, quindi riattiva i prompt sospesi. Non riesce se il progetto non è un pitch.
</ParamField>

<ParamField body="description" type="string">
  Descrizione aggiornata (max 500 caratteri).
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{"name": "Finseo — Growth", "description": "Primary Finseo GTM project"}'
```

```python Python
import requests

project_id = "67a1c2d3e4f5061728394a5b"
r = requests.put(
    f"https://api.finseo.ai/v1/projects/{project_id}",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json={"name": "Finseo — Growth", "description": "Primary Finseo GTM project"},
)
print(r.json()["data"])
```

</RequestExample>
