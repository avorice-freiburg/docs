---
title: Crea un Prompt
api: POST /v1/projects/{projectId}/prompts
---

Aggiunge un nuovo Prompt di Tracking a un progetto. Finseo eseguirà questo Prompt sui modelli specificati e registrerà la visibilità del tuo brand rispetto ai concorrenti su ChatGPT, Claude e Perplexity.

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>


<ParamField body="prompt" type="string" required>
  Testo del Prompt (1–500 caratteri).
</ParamField>

<ParamField body="models" type="array">
  Identificatori dei modelli; default `["chatgpt", "claude", "perplexity"]`.
</ParamField>

<ParamField body="language" type="string" default="en">
  Codice lingua del Prompt.
</ParamField>

<ParamField body="tags" type="array">
  Tag facoltativi (stringhe) per filtrare nelle analytics.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "models": ["chatgpt", "claude", "perplexity"],
    "language": "en",
    "tags": ["comparison", "Finseo"]
  }'
```

```python Python
import requests

payload = {
    "prompt": "How does Finseo compare to traditional SEO suites?",
    "models": ["chatgpt", "claude", "perplexity"],
    "language": "en",
    "tags": ["comparison", "Finseo"],
}
r = requests.post(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
print(r.json()["data"])
```
