---
title: Elenca i Prompt
api: GET /v1/projects/{projectId}/prompts
---

Elenca i Prompt tracciati di un progetto con visibilità, numero di Mentions, citazioni e Sentiment per il periodo selezionato. Finseo valuta questi Prompt su ChatGPT, Claude, Perplexity e altri modelli.

Per ogni Prompt, tutti i conteggi si riferiscono alle risposte AI del periodo selezionato (`resultCount`; vedi [KPI e metriche](/it/getting-started/kpis)):

- `isVisible` — il brand è stato visibile in almeno una risposta: nominato nel testo della risposta O dominio proprio citato come fonte
- `totalMentions` / `mentionRate` — risposte che nominano il brand nel testo, e quel conteggio in % di `resultCount` (**Mention Rate**)
- `ownDomainCitations` / `citationRate` — risposte che citano il dominio proprio (o un alias di dominio configurato) come fonte, e quel conteggio in % di `resultCount` (**Citation Rate**)

`avgPosition` nella risposta è la **Mention Depth**: quanto in profondità nel testo della risposta compare la menzione del brand (0% = all'inizio). Non è una posizione in classifica — per il KPI ordinale Position vedi l'[Endpoint dei concorrenti](/it/api-reference/competitors/ranking) (`avgMentionOrder`) e [KPI e metriche](/it/getting-started/kpis).

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Durata della finestra mobile, es. `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Filtra i risultati su un singolo modello (es. `chatgpt`).
</ParamField>

<ParamField query="language" type="string">
  Filtro per codice lingua ISO (es. `en`, `de`).
</ParamField>

<ParamField query="tags" type="string">
  Stringa array JSON o nomi di Tag separati da virgola per filtrare i Prompt.
</ParamField>

<ParamField query="search" type="string">
  Corrispondenza per sottostringa sul testo del Prompt, senza distinzione tra maiuscole e minuscole.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Numero di pagina (a partire da 1).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Dimensione della pagina (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts?timeframe=30d&limit=10&page=1' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

params = {"timeframe": "30d", "limit": 10, "page": 1, "search": "Finseo"}
r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params=params,
)
body = r.json()["data"]
first = body["prompts"][0]
print(body["totalCount"], first["prompt"], first["mentionRate"], first["citationRate"])
```
