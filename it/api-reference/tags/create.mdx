---
title: Applica un Tag ai Prompt
api: POST /v1/projects/{projectId}/tags
---

Aggiunge un Tag a uno o più Prompt. Il Tag viene unito ai Tag già presenti sul Prompt, così puoi organizzare le coorti di Tracking di Finseo senza sostituire le altre etichette.

<ParamField path="projectId" type="string" required>
  Identificatore del progetto.
</ParamField>


<ParamField body="name" type="string" required>
  Nome del Tag (1–100 caratteri).
</ParamField>

<ParamField body="promptIds" type="array" required>
  Elenco non vuoto di UUID dei Prompt da aggiornare.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/tags \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Q1-2026",
    "promptIds": ["a1b2c3d4-e5f6-7890-abcd-ef1234567890", "b2c3d4e5-f6a7-8901-bcde-f12345678901"]
  }'
```

```python Python
import requests

payload = {
    "name": "Q1-2026",
    "promptIds": [
        "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "b2c3d4e5-f6a7-8901-bcde-f12345678901",
    ],
}
r = requests.post(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/tags",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
print(r.json()["data"])
```

</RequestExample>

<ResponseExample>

```json
{
  "data": {
    "tag": "Q1-2026",
    "appliedTo": 2
  }
}
```

</ResponseExample>
