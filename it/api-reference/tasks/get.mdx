---
title: Ottieni Task
api: GET /v1/projects/{projectId}/tasks/{taskId}
description: Leggi una task di ottimizzazione completa — descrizione, piano d'azione passo-passo, le evidenze che l'hanno generata e il content plan strutturato per le task di contenuto.
---

Restituisce la task completa: la descrizione integrale, un piano d'azione passo-passo, le evidenze (dati e prompt o fonti coinvolti) che hanno generato la task e — per le task di contenuto — un `contentPlan` strutturato con la pagina target, il template e i prompt che il contenuto deve coprire.

Ottieni il `taskId` da [Elenca Task](/it/api-reference/tasks/list) (campo `id`).

<ParamField path="projectId" type="string" required>L'ID del progetto</ParamField>
<ParamField path="taskId" type="string" required>L'ID della task (UUID) da Elenca Task</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/tasks/05ba7f64-9c1e-4f2a-8d3b-1a2b3c4d5e6f' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/tasks/{task_id}",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)
task = response.json()["data"]

print(task["title"])
for i, step in enumerate(task["steps"], 1):
    print(f"{i}. {step}")
```

```javascript Node.js
const res = await fetch(
  `https://api.finseo.ai/v1/projects/${projectId}/tasks/${taskId}`,
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const { data: task } = await res.json();
console.log(task.title, task.steps);
```
