# Finseo API

Monitora come il tuo brand appare in ChatGPT, Claude, Perplexity e altre piattaforme AI. La Finseo Customer API ti permette di recuperare metriche di visibilità, gestire prompt, analizzare i competitor ed esportare dati.

## Base URL

```
https://api.finseo.ai/v1
```

## Esempio rapido

<CodeGroup>

```bash cURL
curl --request GET \
  --url https://api.finseo.ai/v1/projects/YOUR_PROJECT_ID/metrics?timeframe=30d \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

headers = {"Authorization": "Bearer YOUR_API_KEY"}
response = requests.get(
    "https://api.finseo.ai/v1/projects/YOUR_PROJECT_ID/metrics",
    headers=headers,
    params={"timeframe": "30d"}
)

data = response.json()["data"]
print(f"Visibility Rate: {data['current']['visibilityRate']}%")
print(f"Mentions: {data['current']['mentions']}")
print(f"Change: {data['changes']['visibilityRateChange']:+.1f}%")
```

```javascript Node.js
const response = await fetch(
  "https://api.finseo.ai/v1/projects/YOUR_PROJECT_ID/metrics?timeframe=30d",
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);

const { data } = await response.json();
console.log(`Visibility: ${data.current.visibilityRate}%`);
console.log(`Mentions: ${data.current.mentions}`);
```

## Formato della risposta

Tutti gli endpoint restituiscono un envelope JSON uniforme:

| Campo | Descrizione |
|-------|-------------|
| `data` | Il payload della risposta |
| `meta` | Informazioni di paginazione (quando applicabile) |
| `error` | Dettagli dell'errore (solo in caso di errore) |

## Codici di errore

| Code | Status | Descrizione |
|------|--------|-------------|
| `UNAUTHORIZED` | 401 | API key mancante o non valida |
| `FORBIDDEN` | 403 | Scope insufficienti |
| `NOT_FOUND` | 404 | Risorsa non trovata |
| `VALIDATION_ERROR` | 400 | Parametri non validi |
| `RATE_LIMIT_EXCEEDED` | 429 | Troppe richieste |
| `PROJECT_ACCESS_DENIED` | 403 | L'API key non può accedere a questo progetto |
| `INTERNAL_ERROR` | 500 | Errore del server |
