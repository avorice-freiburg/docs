Tutti i connettori qui sotto sono disponibili nella tua dashboard in **Settings → Integrations**.

## Integrazioni di attribution

Le integrazioni di attribution usano una delle due opzioni:

- Un URL di webhook del progetto per form e CRM.
- La Customer API per strumenti di automazione come Zapier, Make o n8n.

Gli URL dei webhook hanno questo aspetto:

```text
https://app.finseo.ai/api/attribution/webhook/PROJECT_ID?source=SOURCE&token=WEBHOOK_TOKEN
```

Il parametro `source` aiuta Finseo a scegliere il parser corretto. Il `token` protegge l'endpoint.

## Sorgenti di attribution supportate

| Sorgente | Percorso consigliato | Note |
| --- | --- | --- |
| HubSpot | Webhook di workflow | Richiede un'azione di workflow HubSpot che invii un webhook. Per le azioni webhook native potrebbe essere necessario Data Hub Pro/Enterprise. |
| Salesforce | Flow HTTP Callout | Usa JSON da Flow Builder. Le Outbound Message native di Salesforce inviano XML e non sono supportate. |
| Typeform | Webhook nativo | Aggiungi una domanda "Come ci hai trovati?" e invia tutte le risposte a Finseo. |
| Jotform | Webhook nativo | Finseo gestisce i payload multipart/form-data e `rawRequest` di Jotform. |
| Gravity Forms | Webhooks Add-On | Invia JSON e mappa il campo di attribution se necessario. |
| Formstack | Webhook nativo | Invia le submission dei form come JSON. |
| Attio | Webhook nativo | Invia i payload di creazione/aggiornamento dei record con campi personalizzati. |
| Pipedrive | Webhook di automazione | Invia i campi di deal e persona dalle automazioni. |
| Close | Webhook nativo | Invia eventi di lead o contatto. |
| Calendly | Sottoscrizione webhook | Invia le risposte degli invitati dalle domande di prenotazione. |
| Intercom | Webhook nativo | Invia eventi di contatto o conversazione con attributi personalizzati. |
| Zapier / Make / n8n | Richiesta HTTP | Usa la Finseo API o un webhook generico e mappa i campi manualmente. |

## HubSpot

1. In Finseo, apri **Integrations** e seleziona **HubSpot**.
2. Copia l'URL del webhook.
3. In HubSpot, vai su **Automations -> Workflows**.
4. Crea un workflow attivato da una submission di form o dalla creazione di un contatto.
5. Aggiungi un'azione **Send webhook**.
6. Incolla l'URL del webhook di Finseo.
7. Invia un lead di test e controlla **Attribution** in Finseo.

Finseo cerca campi comuni come `email`, `firstname`, `lastname`, `how_did_you_find_us`, `deal_amount` e `amount`.

## Salesforce

Usa **Flow HTTP Callout**, non le Outbound Message native.

```json
{
  "LeadSource": "ChatGPT",
  "Email": "buyer@example.com",
  "Name": "Alex Buyer",
  "Id": "00Qxx0000012345",
  "Amount": 8500,
  "CurrencyIsoCode": "USD"
}
```

Finseo mappa `LeadSource` sul canale di attribution, `Email` sull'email del rispondente, `Name` sul nome del rispondente, `Amount` sul valore del deal e `CurrencyIsoCode` sulla valuta.

## Typeform e Jotform

Per gli strumenti di form, aggiungi una domanda come:

```text
How did you find us?
```

Buone opzioni di risposta:

- ChatGPT
- Perplexity
- Claude
- Google
- Social media
- Amico o collega
- Ads
- Altro

Poi aggiungi l'URL del webhook di Finseo nelle impostazioni webhook del form. Finseo riceve l'intera submission ed estrae la risposta di attribution.

## Zapier, Make e n8n

Usa questi strumenti quando la tua sorgente non ha un webhook nativo o quando vuoi trasformare i campi prima di inviarli a Finseo.

```json
{
  "channelId": "{{how_did_you_find_us}}",
  "respondentEmail": "{{email}}",
  "respondentName": "{{name}}",
  "respondentExternalId": "{{crm_id}}",
  "dealValue": "{{amount}}",
  "dealCurrency": "{{currency}}",
  "metadata": {
    "source_tool": "zapier",
    "form": "{{form_name}}"
  }
}
```

Puoi inviarlo all'URL del webhook del progetto oppure alla [Create Attribution API](/api-reference/attribution/submit).

## Mapping dei campi

Se uno strumento invia campi con nomi insoliti, invia prima un payload di test. Finseo crea un workflow di Attribution dalla struttura in entrata. Apri **Attribution -> Workflows** e mappa i campi su:

- Risposta di attribution
- Email
- Nome
- Valore del deal
- Valuta del deal
- ID del form

Usa le regole quando un campo sorgente deve essere tradotto. Per esempio, mappa `utm_source contains chatgpt` su `AI Search`.

## Checklist di test

- Invia una submission di test dallo strumento sorgente.
- Conferma che la risposta compaia in **Attribution**.
- Conferma che la categoria del canale sia corretta, soprattutto per le sorgenti AI.
- Aggiungi `dealValue` e `dealCurrency` se vuoi il reporting dei ricavi.
- Aggiungi un `respondentExternalId` stabile come ID ordine, ID lead o ID deal.
- Mantieni coerenti i nomi dei campi tra mercati e paesi diversi.
