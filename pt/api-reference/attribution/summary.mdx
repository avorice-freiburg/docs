---
title: Obter Resumo de Atribuição
api: GET /v1/projects/{projectId}/attribution/summary
---

Obtenha dados agregados de atribuição mostrando a distribuição por canal, o percentual de busca com IA e a receita total atribuída. Use isto para entender qual percentual dos seus leads vem de busca com IA em comparação com outros canais.

<ParamField path="projectId" type="string" required>
  O ID do projeto.
</ParamField>

<ParamField query="days" type="integer" default="30">
  Número de dias a considerar retroativamente.
</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/PROJECT_ID/attribution/summary?days=30' \
  --header 'Authorization: Bearer sk_live_xxxxxxxx'
```
</RequestExample>
