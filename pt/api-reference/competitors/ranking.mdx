---
title: Listar Concorrentes
api: GET /v1/projects/{projectId}/competitors
---

Retorna os concorrentes ranqueados por visibilidade em IA: visibilidade, mention rate, citation rate, Mentions, Share of Voice, posição e Sentiment. Use isto para ver como a Finseo se compara a outras marcas nas respostas do ChatGPT, Claude e Perplexity.

Três taxas de presença são retornadas por concorrente, todas como parcela de `totalResults` (veja [KPIs explicados](/pt/getting-started/kpis)):

- `visibilityRate` — **Visibility**: % de respostas em que a marca está visível, ou seja, nomeada no texto da resposta OU com seu domínio citado como fonte (a coluna "Visibility" do dashboard; `visibleResults` é a contagem). `visibilityIsMentionOnly: true` sinaliza linhas em que o componente de citações não pôde ser resolvido e o valor é igual à taxa baseada apenas em menções.
- `mentionRate` — **Mention Rate**: % de respostas que nomeiam a marca no texto (`totalMentions` é a contagem).
- `citationRate` — **Citation Rate**: % de respostas que citam o domínio da marca como fonte (`totalCitations` é a contagem); `null` quando as citações não puderam ser resolvidas para a marca.

Uma resposta pode contar tanto para `mentionRate` quanto para `citationRate`, então `visibilityRate ≤ mentionRate + citationRate`.

Duas métricas de posição são retornadas por concorrente:

- `avgMentionOrder` — o KPI ordinal **Position**: posição média entre todas as marcas nomeadas em uma resposta (1 = nomeada primeiro, quanto menor, melhor). É o valor no estilo `#2.3` exibido na página de concorrentes do dashboard.
- `averagePosition` — **Mention Depth**: a que profundidade do *texto* da resposta a menção aparece (0% = bem no topo). Não é uma posição de ranking; mantido com este nome por compatibilidade retroativa.

<ParamField path="projectId" type="string" required>
  Identificador do projeto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Janela de análise, por exemplo `7d`, `30d`.
</ParamField>

<ParamField query="model" type="string">
  Filtre os resultados de Tracking para um único modelo.
</ParamField>

<ParamField query="language" type="string">
  Filtre os Prompts por idioma.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON ou Tags de Prompt separadas por vírgula.
</ParamField>

<ParamField query="search" type="string">
  Filtre por parte do nome ou domínio do concorrente.
</ParamField>

<ParamField query="sortBy" type="string" default="visibility">
  Um de `visibility` (nomeada OU citada), `mentions`, `position`, `sentiment`, `name`.
</ParamField>

<ParamField query="sortDir" type="string" default="desc">
  `asc` ou `desc`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número da página.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Tamanho da página (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors?timeframe=30d&sortBy=mentions&limit=20' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/competitors",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "30d", "sortBy": "visibility", "limit": 20},
)
competitors = r.json()["data"]["competitors"]
print([c["name"] for c in competitors if c["isUserBrand"]])
```
