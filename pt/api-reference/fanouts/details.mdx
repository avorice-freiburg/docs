---
title: Obter Detalhes de Fan-out
api: GET /v1/projects/{projectId}/fanouts/details
description: Obtenha os detalhes de cada ocorrência de uma única consulta de fan-out — todo resultado de Tracking cujas consultas de fan-out contêm exatamente este texto.
---

Retorna todos os resultados de Tracking em que esta consulta de fan-out específica foi gerada, incluindo o Prompt de origem, o modelo, o timestamp, a visibilidade e as Mentions.

Use este Endpoint para aprofundar a análise a partir da lista agregada de fan-outs (`GET /fanouts`) até as ocorrências individuais.

<ParamField path="projectId" type="string" required>O ID do projeto</ParamField>
<ParamField query="query" type="string" required>O texto exato da consulta de fan-out (correspondência sem diferenciar maiúsculas de minúsculas)</ParamField>
<ParamField query="timeframe" type="string" default="90d">Janela de tempo — `7d`, `30d`, `90d`, `365d`, ou `all` para pesquisar em todos os fan-outs já registrados</ParamField>
<ParamField query="startDate" type="string">Data de início personalizada (YYYY-MM-DD)</ParamField>
<ParamField query="endDate" type="string">Data de fim personalizada (YYYY-MM-DD)</ParamField>
<ParamField query="tags" type="string">Tags separadas por vírgula para filtrar os Prompts de origem</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/fanouts/details?query=best+CRM+for+small+business+2026&timeframe=30d' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/fanouts/details",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"query": "best CRM for small business 2026", "timeframe": "30d"}
)
data = response.json()["data"]

print(f"Found {data['totalOccurrences']} occurrences of '{data['query']}'")
for occ in data["occurrences"]:
    print(f"  {occ['model']} on {occ['timestamp']} — visible: {occ['visible']}")
```
