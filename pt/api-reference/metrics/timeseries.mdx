---
title: Série Temporal de Métricas
api: GET /v1/projects/{projectId}/metrics/timeseries
---

Retorna métricas diárias de visibilidade em IA para geração de gráficos. Cada linha em `data.chartData` corresponde a um dia do calendário dentro do período derivado de `timeframe`, ou dentro de `startDate` / `endDate` quando ambos são fornecidos. Ideal para linhas de tendência da Finseo no ChatGPT, Claude e Perplexity.

Campos por dia (todas as contagens são respostas de IA daquele dia; veja [KPIs explicados](/pt/getting-started/kpis)):

| Campo | Significado |
| --- | --- |
| `totalResults` | Respostas de IA analisadas naquele dia |
| `visible` / `notVisible` | Respostas em que a marca está visível (nomeada no texto OU domínio próprio citado) / não visível — `visible ÷ totalResults` é a **Visibility** do dashboard |
| `mentions` | Respostas que nomeiam a marca no texto — `mentions ÷ totalResults` é a **Mention Rate** |
| `cited` | Respostas que citam o domínio próprio (ou um alias de domínio) como fonte — `cited ÷ totalResults` é a **Citation Rate**. `null` quando o dia foi servido a partir de um rollup que não carrega citações |
| `mentionOrder` | Posição ordinal média entre as marcas nomeadas (1 = nomeada primeiro; o KPI **Position** do dashboard), `null` quando a marca não foi nomeada |
| `position` | Profundidade da menção — a que profundidade do texto da resposta a menção aparece (0 = topo) |
| `sentiment` | Pontuação média de sentimento (0–100) nas respostas visíveis |
| `uniquePrompts` | Prompts distintos com pelo menos uma resposta naquele dia |

<ParamField path="projectId" type="string" required>
  Identificador do projeto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Janela móvel quando `startDate` / `endDate` não são usados.
</ParamField>

<ParamField query="startDate" type="string">
  Data ISO `YYYY-MM-DD` (use com `endDate`).
</ParamField>

<ParamField query="endDate" type="string">
  Data ISO `YYYY-MM-DD` (use com `startDate`).
</ParamField>

<ParamField query="model" type="string">
  Filtre para um único modelo.
</ParamField>

<ParamField query="language" type="string">
  Filtro por idioma do Prompt.
</ParamField>

<ParamField query="tags" type="string">
  Array JSON ou Tags separadas por vírgula.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries?timeframe=14d' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/metrics/timeseries",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params={"timeframe": "14d", "model": "chatgpt"},
)
series = r.json()["data"]["chartData"]
last = series[-1]
print(last["date"], last["visible"] / last["totalResults"], last["mentions"], last["cited"])
```
