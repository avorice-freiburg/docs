---
title: Criar Projeto
api: POST /v1/projects
---

Cria um novo projeto. A Finseo fará o Tracking da visibilidade em IA da marca associada a este projeto no ChatGPT, Claude, Perplexity e nos modelos configurados.


<ParamField body="name" type="string" required>
  Nome de exibição (1–200 caracteres).
</ParamField>

<ParamField body="language" type="string" required>
  Idioma da análise da marca e dos prompts gerados (sem diferenciar maiúsculas).
  Valores aceitos: `en`, `de`, `fr`, `es`, `it`, `nl`, `pt`, `pl`, `sv`, `da`, `tr`, `ja`,
  `no`, `fi`, `cs`, `ru`, `zh`, `zh-tw`, `ko`, `hi`, `ar`, `he`.
</ParamField>

<ParamField body="websiteUrl" type="string">
  URL canônica do site; usada para inferir `domain` quando omitido.
</ParamField>

<ParamField body="domain" type="string">
  Domínio raiz (por exemplo, `finseo.ai`). Opcional se `websiteUrl` for fornecido.
</ParamField>

<ParamField body="description" type="string">
  Notas opcionais (máx. 500 caracteres).
</ParamField>

<ParamField body="isPitch" type="boolean">
  Cria um **projeto de pitch** sem taxa de projeto, limitado a 50 prompts e
  pausado automaticamente ao fim da janela. Ideal para análises pontuais de
  prospects por agentes de vendas. Os slots dependem do pacote de agência
  (250 no Agency Starter e 500 no Agency Studio).
</ParamField>

<ParamField body="pitchDurationDays" type="number" default="14">
  Janela do pitch em dias: `1` (execução única), `7` ou `14`. Ignorado se
  `isPitch` não for `true`. Converta um pitch ganho com
  [Atualizar projeto](/api-reference/projects/update) e `convertFromPitch`.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.finseo.ai/v1/projects \
  --header 'Authorization: Bearer sk_live_xxxxxxxx' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks"
  }'
```

```python Python
import requests

payload = {
    "name": "Finseo Labs",
    "websiteUrl": "https://labs.finseo.ai",
    "language": "en",
    "description": "Experimental prompts and benchmarks",
}
r = requests.post(
    "https://api.finseo.ai/v1/projects",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    json=payload,
)
created = r.json()["data"]
print(created["id"])
```
