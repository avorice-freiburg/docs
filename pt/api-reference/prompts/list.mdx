---
title: Listar Prompts
api: GET /v1/projects/{projectId}/prompts
---

Lista os Prompts monitorados de um projeto com visibilidade, contagem de Mentions, citações e Sentiment para o período selecionado. A Finseo avalia esses Prompts no ChatGPT, Claude, Perplexity e outros modelos.

Por Prompt, todas as contagens se referem às respostas de IA do período selecionado (`resultCount`; veja [KPIs explicados](/pt/getting-started/kpis)):

- `isVisible` — a marca esteve visível em pelo menos uma resposta: nomeada no texto da resposta OU com o domínio próprio citado como fonte
- `totalMentions` / `mentionRate` — respostas que nomeiam a marca no texto, e essa contagem como % de `resultCount` (**Mention Rate**)
- `ownDomainCitations` / `citationRate` — respostas que citam o domínio próprio (ou um alias de domínio configurado) como fonte, e essa contagem como % de `resultCount` (**Citation Rate**)

`avgPosition` na resposta é a **Mention Depth**: a que profundidade do texto da resposta a menção da marca aparece (0% = bem no topo). Não é uma posição de ranking — para o KPI ordinal Position, veja o [endpoint de concorrentes](/pt/api-reference/competitors/ranking) (`avgMentionOrder`) e [KPIs explicados](/pt/getting-started/kpis).

<ParamField path="projectId" type="string" required>
  Identificador do projeto.
</ParamField>

<ParamField query="timeframe" type="string" default="30d">
  Duração da janela móvel, por exemplo `7d`, `30d`, `90d`.
</ParamField>

<ParamField query="model" type="string">
  Filtre os resultados para um único modelo (por exemplo, `chatgpt`).
</ParamField>

<ParamField query="language" type="string">
  Filtro por código de idioma ISO (por exemplo, `en`, `de`).
</ParamField>

<ParamField query="tags" type="string">
  String de array JSON ou nomes de Tags separados por vírgula para filtrar os Prompts.
</ParamField>

<ParamField query="search" type="string">
  Correspondência de parte do texto do Prompt, sem diferenciar maiúsculas de minúsculas.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número da página (a partir de 1).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Tamanho da página (1–500).
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts?timeframe=30d&limit=10&page=1' \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

params = {"timeframe": "30d", "limit": 10, "page": 1, "search": "Finseo"}
r = requests.get(
    "https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b/prompts",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
    params=params,
)
body = r.json()["data"]
first = body["prompts"][0]
print(body["totalCount"], first["prompt"], first["mentionRate"], first["citationRate"])
```
