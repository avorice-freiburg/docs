---
title: Obter Task
api: GET /v1/projects/{projectId}/tasks/{taskId}
description: Leia uma task de otimização completa — descrição, plano de ação passo a passo, as evidências que a originaram e o content plan estruturado em tasks de conteúdo.
---

Devolve a task completa: a descrição integral, um plano de ação passo a passo, as evidências (dados e prompts ou fontes afetados) que originaram a task e — em tasks de conteúdo — um `contentPlan` estruturado com a página alvo, o template e os prompts que o conteúdo deve cobrir.

Obtenha o `taskId` em [Listar Tasks](/pt/api-reference/tasks/list) (campo `id`).

<ParamField path="projectId" type="string" required>O ID do projeto</ParamField>
<ParamField path="taskId" type="string" required>O ID da task (UUID) de Listar Tasks</ParamField>

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.finseo.ai/v1/projects/proj_abc123/tasks/05ba7f64-9c1e-4f2a-8d3b-1a2b3c4d5e6f' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}/tasks/{task_id}",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)
task = response.json()["data"]

print(task["title"])
for i, step in enumerate(task["steps"], 1):
    print(f"{i}. {step}")
```

```javascript Node.js
const res = await fetch(
  `https://api.finseo.ai/v1/projects/${projectId}/tasks/${taskId}`,
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const { data: task } = await res.json();
console.log(task.title, task.steps);
```
