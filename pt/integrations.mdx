## Integrações de Attribution

As integrações de Attribution usam:

- Um URL de webhook do projeto para formulários e CRMs.
- A Customer API para ferramentas de automação como Zapier, Make ou n8n.

Os URLs de webhook têm este aspeto:

```text
https://app.finseo.ai/api/attribution/webhook/PROJECT_ID?source=SOURCE&token=WEBHOOK_TOKEN
```

O parâmetro `source` ajuda a Finseo a escolher o parser certo. O `token` protege o endpoint.

## Fontes de atribuição suportadas

| Fonte | Caminho recomendado | Notas |
| --- | --- | --- |
| HubSpot | Webhook de workflow | Requer uma ação de workflow do HubSpot que envie um webhook. Para ações de webhook nativas pode ser necessário o Data Hub Pro/Enterprise. |
| Salesforce | Flow HTTP Callout | Use JSON do Flow Builder. As Outbound Messages nativas do Salesforce enviam XML e não são suportadas. |
| Typeform | Webhook nativo | Adicione uma pergunta "Como é que nos encontrou?" e envie todas as respostas para a Finseo. |
| Jotform | Webhook nativo | A Finseo processa payloads multipart/form-data e `rawRequest` do Jotform. |
| Gravity Forms | Webhooks Add-On | Envie JSON e mapeie o campo de atribuição, se necessário. |
| Formstack | Webhook nativo | Envie as submissões de formulário como JSON. |
| Attio | Webhook nativo | Envie payloads de criação/atualização de registos com campos personalizados. |
| Pipedrive | Webhook de automação | Envie campos de negócio e de pessoa a partir de automações. |
| Close | Webhook nativo | Envie eventos de lead ou de contacto. |
| Calendly | Subscrição de webhook | Envie as respostas dos convidados das perguntas de marcação. |
| Intercom | Webhook nativo | Envie eventos de contacto ou de conversa com atributos personalizados. |
| Zapier / Make / n8n | Pedido HTTP | Use a API da Finseo ou um webhook genérico e mapeie os campos manualmente. |

## HubSpot

1. Na Finseo, abra **Integrations** e selecione **HubSpot**.
2. Copie o URL do webhook.
3. No HubSpot, vá a **Automations -> Workflows**.
4. Crie um workflow acionado por uma submissão de formulário ou criação de contacto.
5. Adicione uma ação **Send webhook**.
6. Cole o URL do webhook da Finseo.
7. Submeta um lead de teste e verifique **Attribution** na Finseo.

A Finseo procura campos comuns como `email`, `firstname`, `lastname`, `how_did_you_find_us`, `deal_amount` e `amount`.

## Salesforce

Use **Flow HTTP Callout**, não as Outbound Messages nativas.

```json
{
  "LeadSource": "ChatGPT",
  "Email": "buyer@example.com",
  "Name": "Alex Buyer",
  "Id": "00Qxx0000012345",
  "Amount": 8500,
  "CurrencyIsoCode": "USD"
}
```

A Finseo mapeia `LeadSource` para o canal de atribuição, `Email` para o email do respondente, `Name` para o nome do respondente, `Amount` para o valor do negócio e `CurrencyIsoCode` para a moeda.

## Typeform e Jotform

Nas ferramentas de formulários, adicione uma pergunta como:

```text
How did you find us?
```

Boas opções de resposta:

- ChatGPT
- Perplexity
- Claude
- Google
- Redes sociais
- Amigo ou colega
- Anúncios
- Outro

Depois adicione o URL do webhook da Finseo nas definições de webhook do formulário. A Finseo recebe a submissão completa e extrai a resposta de atribuição.

## Zapier, Make e n8n

Use estes quando a sua ferramenta de origem não tem webhook nativo ou quando quer transformar campos antes de os enviar para a Finseo.

```json
{
  "channelId": "{{how_did_you_find_us}}",
  "respondentEmail": "{{email}}",
  "respondentName": "{{name}}",
  "respondentExternalId": "{{crm_id}}",
  "dealValue": "{{amount}}",
  "dealCurrency": "{{currency}}",
  "metadata": {
    "source_tool": "zapier",
    "form": "{{form_name}}"
  }
}
```

Pode enviar isto para o URL de webhook do projeto ou para a [Create Attribution API](/api-reference/attribution/submit).

## Mapeamento de campos

Se uma ferramenta enviar campos com nomes invulgares, envie primeiro um payload de teste. A Finseo cria um workflow de Attribution a partir da estrutura recebida. Abra **Attribution -> Workflows** e mapeie os campos para:

- Resposta de atribuição
- Email
- Nome
- Valor do negócio
- Moeda do negócio
- ID do formulário

Use regras quando um campo de origem precisa de tradução. Por exemplo, mapeie `utm_source contains chatgpt` para `AI Search`.

## Checklist de testes

- Envie uma submissão de teste a partir da ferramenta de origem.
- Confirme que a resposta aparece em **Attribution**.
- Confirme que a categoria do canal está correta, especialmente para fontes de IA.
- Adicione `dealValue` e `dealCurrency` se quiser reporting de receita.
- Adicione um `respondentExternalId` estável, como o ID da encomenda, ID do lead ou ID do negócio.
- Mantenha os nomes dos campos consistentes entre mercados e países.
